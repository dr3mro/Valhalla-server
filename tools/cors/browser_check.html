Valhalla CORS browser check

Runs real cross-origin fetch calls from this page, so the browser itself performs the preflight and applies its CORS rules. A request passes when fetch resolves: any HTTP status counts (a fake token gives 401 on purpose, nothing is changed). It fails when the browser blocks it (TypeError: Failed to fetch); open DevTools → Console for the exact CORS reason.

Serve this folder from the origin your React app uses, for example cd tools/cors && python3 -m http.server 3000, then open http://localhost:3000/browser_check.html.
