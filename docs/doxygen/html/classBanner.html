Detailed Description

Stateless collection of static helpers for stdout startup output.

All functions are static and use fmt for coloured output. There are no members and no instances are required; the class only groups related printing utilities. Shared static data is confined to the local statics in get_random_color() and the cached logo string.

◆ get_random_color()

fmt::color Banner::get_random_color ( )
inlinestatic

Picks a random colour for the ASCII logo.

The palette is initialised once as a function-local static. A hardware random_device seeds a fresh mt19937 on each call, and a static uniform distribution selects an index in [0, colors.size() - 1].

Returns
One of the palette colours.
Note
The returned colour is decorative; no significance should be attached to it.
The shared static distribution is not locked, but this function is called only once during startup, so there is no concurrent invocation in this server.
