Detailed Description

The pool for deliberately slow password work (hashing and verification), so it never runs on a Drogon IO thread.

Keeping password operations off the IO threads prevents them from blocking request handling. Queueing, fair dispatch, zero-worker inline mode and shutdown semantics are inherited from BoundedExecutor; see that class for the queue and inline-mode rules. Think of it as a queue with a fixed number of helpers: requests drop a job in the queue, and a free helper picks it up.
