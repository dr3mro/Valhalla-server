1/**
2 * @file defaults.hpp
3 * @brief Default values for every environment-driven configuration option.
4 * @details This header declares a set of compile-time constants, grouped by
5 * purpose into small namespaces. They are the "fallback" values the
6 * configuration system uses whenever an environment variable is not set or
7 * cannot be understood. Because they are baked into the binary, they guarantee
8 * the server still has sensible, complete settings even on a fresh machine with
9 * no configuration at all. A few values are deliberately insecure development
10 * placeholders and are meant to be replaced in a real deployment.
11 *
12 * WHY THIS FILE MATTERS IN THE SERVER:
13 * This is the single source of truth for "what the server does when nobody
14 * tells it what to do". Every Configurator section constructor passes one of
15 * these constants to EnvLoader as the default, so changing a number here
16 * changes the out-of-the-box behaviour everywhere. It also documents, in one
17 * place, the expected units and ranges for each setting (seconds, milliseconds,
18 * ports). Without it, a missing environment variable would leave settings
19 * undefined and startup would fail.
20 *
21 * CONCEPTS TO LEARN (for beginners):
22 * - Environment variables: https://man7.org/linux/man-pages/man7/environ.7.html
23 * - Fixed-width integer types such as uint32_t:
24 * https://en.cppreference.com/w/cpp/types/integer
25 *
26 * @author Amr Osman <dr3mro@gmail.com>
27 * @date 2026-11-16
28 */
29
