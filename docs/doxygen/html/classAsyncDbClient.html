Detailed Description

Store-registered holder for the Drogon PostgreSQL client used when DB_ASYNC=true.

The wrapper holds a shared_ptr<drogon::orm::DbClient>; production instances are created from the DB_* settings. Server::run() registers it in the Store only while DatabaseConfig::async is enabled; the synchronous pool stays in use while the flag is off. Callers fetch it with Store::getObject<AsyncDbClient>(nullptr) and hand the underlying client to asyncdb::execSqlCoro. Tests replace the registered instance through Store::replaceObject; a null client is a valid state meaning "async path unavailable", which the controller treats as std::nullopt. The wrapper itself is non-copyable and non-movable so there is a single long-lived Store-owned instance. It adds no locking of its own; any thread-safety comes from the underlying Drogon DbClient.

See also
createClient, asyncdb::execSqlCoro, DatabaseController::executeQueryCoro

Renders a libpq keyword/value connection string from a database configuration.

Formats the libpq connection string, mapping config.ssl to sslmode.

Parameters
[in]configSource of host, port, database name, user, password and SSL settings.
Returns
host=... port=... dbname=... user=... password=... connect_timeout=2 sslmode=require|disable.
Warning
The returned string contains the database password in clear text; it must not be logged. printValues() on the configuration deliberately redacts the same field.

connect_timeout is a fixed two seconds, independent of DB_* tuning; host and SSL settings may be overridden by the container image but still arrive through this one configuration object.

std::shared_ptr< drogon::orm::DbClient > AsyncDbClient::createClient ( )
static

Builds a Drogon PostgreSQL client from the configuration held in the Store.

Creates the Drogon Pg client from the Store's database configuration.

Reads Configurator::DatabaseConfig from the Store, builds the connection string with connectionString, requests DB_MAX_CONN connections and applies the acquire timeout, converting milliseconds to the seconds Drogon expects.

Returns
A newly created client, ready to be wrapped and registered with Store::registerObject<AsyncDbClient>.
Precondition
A Configurator object is registered in the Store.

newPgClient receives the generated connection string and DB_MAX_CONN; the timeout is then set from DB_ACQUIRE_TIMEOUT_MS. Any connection-establishment work is left to Drogon.
