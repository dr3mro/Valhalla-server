Detailed Description

Abstract contract for clinic-service entity handlers (patients, visits, reports, prescriptions, ...).

Defines the subset of CRUDS operations meaningful for clinic entities plus patient visit retrieval. Implementations (ClinicController) specialize behaviour per entity type: for example only Patient/Visits support Delete, only Patient supports Search and GetVisits. CALLBACK_ is std::function<void(int, const std::string&)>; implementations answer exactly once with an HTTP status code and body on every completing path, including "not implemented" rejections.

Note
Only Create, Read, Delete and GetVisits have coroutine forms in this contract; Update and Search are synchronous only.
