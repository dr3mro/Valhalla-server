Detailed Description

Abstract contract for the request-facing CRUDS handlers exposed for every entity type.

This header declares EntityControllerBase, a pure interface: it lists the ten operations (Create/Read/ Update/Delete/Search and their Async twins) that every ordinary entity handler must provide. It contains no implementation at all - each method ends in = 0, meaning "derived classes must fill this in".

WHY THIS FILE MATTERS IN THE SERVER: It is the contract between the HTTP routing layer and the concrete EntityController<T>. Drogon handlers program against this base type, so they can treat a User, a Patient or a Report uniformly. Without this interface the router would have to know every entity type, and there would be no single place guaranteeing that all entities expose the same CRUDS operations. The real work is done by EntityController (see entitycontroller.hpp), which implements everything declared here.
