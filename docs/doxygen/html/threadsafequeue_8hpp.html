Detailed Description

Mutex-protected FIFO queue with non-blocking accessors.

Defines a template ThreadSafeQueue<T> that wraps std::queue with a single mutex, so several threads can push and pop without corrupting it. push adds items, pop removes and returns the front item, and empty/size/clear/front provide inspection. pop and front never wait: if the queue is empty they return std::nullopt immediately. front returns a copy, so the caller keeps a valid value after the lock is released.

WHY THIS FILE MATTERS IN THE SERVER: Producers (for example worker threads or network callbacks) and consumers often run at the same time. This queue lets them hand items over safely without any locking code at each call site. Because it is a small reusable template, any part of the server can create a thread-safe queue of any copyable type. Without it, each producer/consumer pairing would need its own error-prone locking.
