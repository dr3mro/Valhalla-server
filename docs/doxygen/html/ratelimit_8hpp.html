Detailed Description

Drogon filter that screens requests for DoS/rate-limit violations before authentication.

This file defines the RateLimit filter, the first element of both the INSECURE and SECURE chains. It collects facts about each request (IP address, HTTP method, path, a hash of the headers and the body), bundles them into a DOSDetector::Request and asks GateKeeper for a verdict. Allowed and whitelisted requests continue to the next filter; blacklisted, rate limited, banned or internally-failed requests are stopped immediately with an HTTP error.

WHY THIS FILE MATTERS IN THE SERVER: This filter is the server's first line of defence. Because Drogon runs it before the Auth filter and before any handler, abusive clients are rejected cheaply without spending time on login checks or database queries. It calls GateKeeper, which forwards to DOSDetector; without it the API would have no protection against floods of requests and every client would reach the expensive code paths.

  • Denial-of-service (DoS) and rate limiting: limiting how many requests one client may make.
