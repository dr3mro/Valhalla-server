Detailed Description

Process-wide cache of the database schema used by the validators.

The single static databaseSchema map is populated at construction by querying DatabaseController for every table and its columns, and is thereafter read-only. The object is created eagerly by Server's constructor and owned by Store, so the schema is available before any request validation runs. Copy construction/assignment are allowed but share the same static state; move operations are explicitly disabled.

Note
Because the schema is a startup snapshot, schema changes made externally while the server is running are not reflected until restart.
Warning
Construction terminates the process (or throws) when no tables/columns can be read, so a reachable database is a startup prerequisite.

Validator, DatabaseController, Store, SCHEMA_t

Exceptions
std::runtime_errorif no tables are found.
Note
There is no lazy fallback: a successful construction implies a populated cache.

See DatabaseSchema::DatabaseSchema. Retrieves DatabaseController from Store, asks it for all table names, and calls populateSchema() for each. A missing or empty table list is a fatal startup condition. Note: The exit(EXIT_FAILURE) / "Exiting..." statements after the throw are unreachable; the throw is the active error path.
