Detailed Description

A set of validation exceptions keyed by the actions they relax or assert.

Holds one or more bitmask Action flags and, for each flag group, the set of column names it applies to. A check passes only when the relevant flag is present in action and a matching flag group contains the key being checked. Rules are typically static const objects in controller code, composed with the bitwise operators.

Note
Copying/moving is implicit; the key sets own their strings.
