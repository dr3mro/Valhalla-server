Detailed Description

Implementation for jsonhelper.

Implements the three static helpers declared in jsonhelper.hpp: jsonify creates a single-key JsonCpp object, one stringify overload uses jsoncons' dump_pretty, and the other uses JsonCpp's toStyledString. All are thin wrappers around the two libraries.

WHY THIS FILE MATTERS IN THE SERVER: This is where the actual conversion work lives. Callers across the API include the header and call these functions to build uniform status/error bodies and to print JSON for logs or responses. Keeping the implementations here (rather than inline in the header) means callers do not need to depend on the details of both JSON libraries just to use the helpers.
