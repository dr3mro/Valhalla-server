Detailed Description

Drogon filter that screens requests for DoS/rate-limit violations before authentication.

First element of both the INSECURE and SECURE chains. It builds a DOSDetector::Request from the peer IP, method, path, hashed headers and body, and asks GateKeeper for a verdict. ALLOWED/WHITELISTED continue the chain; blacklist, rate limit, ban and internal error short-circuit with a corresponding HTTP status. The GateKeeper and DOSDetector are shared service-locator objects held for the filter's lifetime.

Note
Unknown verdicts fall through to continuing the chain (default branch).

Classify the request and continue the chain or send a rejection response.

Invoked by Drogon on its IO thread; verdicts map as: BLACKLISTED -> 403, RATELIMITED -> 429, BANNED -> 503, ERROR -> 500. ALLOWED/WHITELISTED and any unrecognised status invoke fccb; rejected requests invoke fcb only.

Parameters
[in]reqRequest supplying peer IP, method, path, headers and body for classification.
[in,out]fcbFilter callback used to send the rejection response.
[in,out]fccbChain callback invoked when the request is permitted.
