Detailed Description

template<typename T>
class ThreadSafeQueue< T >

FIFO container safe for concurrent producers and consumers.

Every operation takes a single mutex, so the queue can be shared between threads without external synchronisation. pop() and front() return std::nullopt immediately when empty: there is no condition variable, so callers never wait for an element to arrive. front() returns a copy rather than a reference, keeping the result valid after the lock is released.

Template Parameters
TElement type; must be copyable (front) and movable (pop, rvalue push).
Note
empty() and size() report a snapshot; another thread can modify the queue as soon as the call returns.
