Detailed Description

Abstract contract for client (User/Provider) handlers: CRUDS plus session and account-state operations.

Extends the entity-style CRUDS surface with authentication (Login/Logout), account suspension state (Suspend/Activate), password reset and service lookup. Implementations (ClientController) authorize via GateKeeper and, for Create/Update, move the expensive password hashing to a dedicated worker pool. CALLBACK_ is std::function<void(int, const std::string&)>; implementations answer exactly once with an HTTP status code and body on every path that completes. Coroutine variants borrow their arguments and must be awaited while those arguments and the controller are alive.

Note
Not every operation has a coroutine variant: Logout and ResetPassword are synchronous only in this contract. The ip_address argument is used by GateKeeper for login/logout bookkeeping.
