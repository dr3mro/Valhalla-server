9 * WHY THIS FILE MATTERS IN THE SERVER:
10 * RadiologyCenters is one of the "service provider" types in the server, next to laboratories and pharmacies. When a
11 * client creates, reads, updates or deletes a radiology centre, or manages its staff, the route layer picks this class
12 * as ServiceController<RadiologyCenters> / StaffController<RadiologyCenters>. Those controllers call the inherited
13 * methods from Service and Entity, which produce the actual SQL. The class also publishes the table name so
14 * PermissionManager can check that the requesting staff member is allowed to change this service. Without this file
15 * there would be no C++ type tying the `radiologycenters` table to the generic CRUD machinery, so radiology-centre
16 * endpoints could not work.

19 * - static constexpr: a value fixed at compile time that belongs to the class, not to one object. https://en.cppreference.com/w/cpp/language/static
20 * - JSON: a text format used to carry request data; this project uses the jsoncons library to read it. https://jsoncons.github.io/jsoncons/
21 * - Template (`template <typename T>`): a blueprint that works with whatever data type the caller supplies. https://en.cppreference.com/w/cpp
