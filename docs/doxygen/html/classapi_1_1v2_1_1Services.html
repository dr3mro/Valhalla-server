Detailed Description

REST controller for service-directory entities (clinics, pharmacies, laboratories, centers).

A {serviceType} path segment selects a ServiceController<T> from a variant registry. Handlers use the shared callback pattern to map controller status codes to JSON HTTP responses, build a Requester from Auth attributes, and run async coroutines or the DbExecutor-backed dispatch according to DatabaseConfig::async. All routes are SECURE.
