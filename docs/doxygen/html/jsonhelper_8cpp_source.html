2 * @file jsonhelper.cpp
3 * @brief Implementation for jsonhelper.
4 * @details Implements the three static helpers declared in jsonhelper.hpp:
5 * jsonify creates a single-key JsonCpp object, one stringify overload
6 * uses jsoncons' dump_pretty, and the other uses JsonCpp's
7 * toStyledString. All are thin wrappers around the two libraries.
8 *
9 * WHY THIS FILE MATTERS IN THE SERVER:
10 * This is where the actual conversion work lives. Callers across the API
11 * include the header and call these functions to build uniform status/error
12 * bodies and to print JSON for logs or responses. Keeping the implementations
13 * here (rather than inline in the header) means callers do not need to depend
14 * on the details of both JSON libraries just to use the helpers.
15 *
16 * CONCEPTS TO LEARN (for beginners):
17 * - Function overloading:

19 * - Qualified names (api::v2::JsonHelper::...):
20 * https://en.cppreference.com/w/cpp/language/identifiers#Qualified_identifiers

22 *

32Json::Value api::v2::JsonHelper::jsonify(const std::string& message) {
33 // Uniform single-key shape for simple status and error bodies.
34 Json::Value object; // An empty JsonCpp value; assigning to
35 // object["Message"] turns it into a JSON object.
36 object["Message"] = message; // Adds one key/value pair so the body is {
37 // "Message": "..." }.
38 return object; // Returns the object by value for the caller to use as a
39 // response body.
40}

49}
