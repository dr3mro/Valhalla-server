2 * @file store.cpp
3 * @brief Defines the Store's single shared registry, lock and generation counter.
4 * @details This file contains no functions. It only gives real storage to the three static variables that store.hpp
5 * declares: a map from a C++ type to its one shared object, a mutex protecting that map, and a counter used to
6 * refresh per-thread caches. The counter starts at 1 so that a brand-new thread, whose remembered value starts
7 * at 0, always performs a lookup the first time it asks for an object.
8 *
9 * WHY THIS FILE MATTERS IN THE SERVER:
10 * These few definitions are the physical storage behind the service locator. Every call to Store::getObject(),
11 * Store::cachedObject() or Store::replaceObject() reads or changes these variables. Without this file the header would
12 * only declare names and the linker would report "undefined reference" errors. Tests also depend on the counter
13 * starting at 1, so a freshly installed fake is noticed on the very first cached lookup.
14 *
15 * CONCEPTS TO LEARN (for beginners):
16 * - None difficult here; this file only provides real storage (a "definition") for names declared in the header.
17 *
18 * @author Amr Osman <dr3mro@gmail.com>
19 * @date 2026-11-16
20 */
