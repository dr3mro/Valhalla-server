Detailed Description

Static helpers for coloured console/status logging.

Declares the Message class: a stateless facade with functions to log at debug, info, warning, error or fatal severity, plus ConfMessage and InitMessage for startup notices. Severity messages go through trantor::Logger and therefore reach the configured Logger/spdlog sinks; the two startup notices print straight to the terminal with a "[Project Valhalla]" prefix. A small colour map and a newline-flattening helper support the formatting.

WHY THIS FILE MATTERS IN THE SERVER: This is the everyday logging interface used all over the code. Instead of every component calling trantor or spdlog directly, they call Message::InfoMessage, Message::ErrorMessage and so on. That centralises colour choices and message formatting, and makes sure records flow into the one logger configured at startup. ConfMessage/InitMessage give friendly, clearly labelled startup output.

CONCEPTS TO LEARN (for beginners):

  • Static member functions: https://en.cppreference.com/w/cpp/language/static#Static_member_functions
  • Function overloading (two MessageImpl versions): https://en.cppreference.com/w/cpp/language/overload_resolution
  • ANSI escape codes for colour: https://en.wikipedia.org/wiki/ANSI_escape_code
