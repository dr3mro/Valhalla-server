Detailed Description

Parsed staff-invitation data and rendering of the invitation link payload.

Constructed from the JSON body of a staff add/remove request. When parsed successfully it can also augment an invite JSON object with the fields the mail template needs, including a base64-encoded link back into the frontend.

Note
parse_status must be checked before relying on the other fields; a missing key leaves them uninitialised.

bool api::v2::Types::StaffData::toInviteJson ( jsoncons::json & invite_json)
inline

Adds the fields required by the invitation email template to invite_json.

The current JSON is base64-encoded into the frontend invite link so the invite payload travels as a single URL-safe token; subject, template, project name and a generate_body placeholder are added alongside it.

Parameters
[in,out]invite_jsonInvitation JSON to augment in place.
Returns
true when the fields were added; false if an exception occurred.
