Detailed Description

Thread-safe bounded pool of reusable resources with idle iteration.

This header defines BlockingPool<T>, a header-only container that holds a fixed set of reusable items as shared_ptrs. release() adds an item and wakes a waiting acquirer; acquire() waits up to a timeout for an item and returns nullptr if none appears; idle() reports the idle count; forEachIdle() visits every idle item under the lock. A mutex protects the deque and a condition variable handles the waiting.

WHY THIS FILE MATTERS IN THE SERVER: This is the generic engine underneath DatabaseConnectionPool. It knows nothing about databases, which makes it reusable and easy to unit test with plain objects. It provides the three properties the server needs: connections are leased one caller at a time, callers wait rather than fail immediately when all are busy, and a bounded wait can be reported as a timeout. Without it the pool would have to reimplement tricky condition-variable logic.
