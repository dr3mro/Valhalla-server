Detailed Description

Abstract contract for the request-facing CRUDS handlers exposed for every entity type.

Declares five operations (Create, Read, Update, Delete, Search), each in a synchronous callback form and in a drogon::Task coroutine form. Implementations (see EntityController) are expected to parse and validate data, authorize the action with requester, construct the entity and delegate persistence to the lower-level Controller. The callback is CALLBACK_ = std::function<void(int, const std::string&)>: implementations invoke it once with an HTTP status code and a response body, including on error paths. 

     The interface itself does not own or store any state; derived

controllers supply the collaborators. The lifetime of callback, requester and data (and of the owning controller) must extend until the coroutine variants complete, because they are borrowed by the coroutine frame.

Note
The const Requester&& parameter is passed by rvalue reference by the existing callers; treat it as a borrowed, immutable principal rather than assuming ownership is transferred.
