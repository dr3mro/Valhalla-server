Detailed Description

REST controller for client accounts (users and providers).

This file defines the Clients controller, which manages user and provider accounts. Its endpoints cover account creation, login and logout, suspend/activate, read, update, delete, search and listing a client's services. A {clientType} part of the URL (users or providers) selects one concrete ClientController from a std::variant registry. Create and login are INSECURE (no token needed); the rest are SECURE and use the identity attributes set by Auth. Most handlers either await async controller coroutines or use executeControllerMethod; read also has a prototype asynchronous implementation for users and providers.

WHY THIS FILE MATTERS IN THE SERVER: This controller is the HTTP front door for client accounts. Drogon routes the /api/v2 clients URLs here, and its handlers call the shared dispatcher, the GateKeeper, the Validator and a DatabaseController to reach the database. It is the only place that issues and invalidates login tokens (through the login/logout controllers), so it underpins authentication for the whole API. Without it clients could not register, sign in or manage their accounts.
