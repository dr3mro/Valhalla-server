Detailed Description

Convenience alias for the id-only payload used by get-services lookups.

This header defines the Provider entity for the "providers" table. It inherits the full validated Client behaviour (create/update with validation, suspend/activate, username checks) and adds one query: getSqlGetServicesStatement, which lists every clinic, pharmacy, radiology centre and laboratory where the provider is an owner, an admin, or listed in the JSON staff array. The provider id is bound twice because it is needed as a number and as text.

WHY THIS FILE MATTERS IN THE SERVER: When a provider logs in, the API needs to know which organisations they belong to so it can show the right workspace. Controllers construct Provider and call getSqlGetServicesStatement to obtain that list. Without it there would be no way to resolve a provider's memberships across the four service tables in one query.

CONCEPTS TO LEARN (for beginners):

  • std::optional: https://en.cppreference.com/w/cpp/utility/optional
  • SQL parameter binding: put $1, $2, ... markers in the SQL and pass the real values separately; see https://en.cppreference.com/w/cpp or the libpqxx documentation. Here there are two markers for the same id because one is used as a bigint and the other as text.
  • UNION ALL: combines the result rows of several SELECT statements into one list.
  • JSONB: a PostgreSQL binary JSON column; jsonb_path_exists searches inside it with a path.
