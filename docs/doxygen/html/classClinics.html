Detailed Description

Service entity bound to the clinics table; the organisation root for clinic cases.

Like the other service types, this is a thin value type that fixes the table name for the inherited Service/Entity SQL builders. CRUD/search and staff management are inherited. Instances are built from one of the api::v2::Types data wrappers, which Entity stores as an EntityType variant. The type satisfies api::v2::Service_t and is selected through the clinics entries of the services and staff route registries. In addition, clinics is the organisation referenced by Case::ORGNAME: every Case permission query joins this table to recover the owning clinic's owner/admin/staff columns through the case's clinic_id. Ownership: the wrapper is copied into the base and is const thereafter; no other resources are owned. No mutable state or locking of its own. Copy and move are deleted by Service: construct a fresh instance per operation.

Note
No default constructor: Entity needs a data wrapper to build statements from.
