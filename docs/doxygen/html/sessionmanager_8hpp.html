Detailed Description

The login/logout flow and the in-memory store of active sessions. (Originally: "Owns the client login flow and the in-memory session cache.").

This header declares SessionManager. It splits logging in into two steps so the slow password check can run on a worker thread, and it keeps active sessions in a shared in-memory cache. Sessions are identified by a "<group>_<id>" key and carry an expiry time.

WHY THIS FILE MATTERS IN THE SERVER: GateKeeper calls this class on every login and logout request. It is the bridge between credentials (username/password) and a valid session/token. Without it, the server could neither prove who a user is nor remember that they are already logged in.
