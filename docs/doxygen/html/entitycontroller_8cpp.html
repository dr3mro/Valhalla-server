Detailed Description

Out-of-line definitions and explicit template instantiations for EntityController<T>.

The synchronous and coroutine implementations mirror each other: each validates the JSON body, checks GateKeeper authorization, builds the entity from a Types data carrier, and delegates to Controller. Explicit instantiation at the bottom makes these templates available to translation units that include only the header (via gatekeeper/includes.hpp).

WHY THIS FILE MATTERS IN THE SERVER: This is where the generic entity pipeline actually lives. Every operation here follows the same shape - parse the JSON, validate it against the table schema, check the caller's permission with GateKeeper, build the entity object, and hand it to Controller for the SQL. The coroutine twins do the same but await the async gate and async DB calls. The bottom of the file lists every concrete entity type so the linker can find these templates; without those instantiations the server would fail to link.
