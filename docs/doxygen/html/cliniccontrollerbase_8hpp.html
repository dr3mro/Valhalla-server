Detailed Description

Abstract contract for clinic-service entity handlers (patients, visits, reports, prescriptions, ...).

Declares ClinicControllerBase, a pure interface for clinical data. It keeps the subset of CRUDS that makes sense for medical records and adds GetVisits for a patient's visit history. As with the other bases, every operation is pure virtual (= 0) and answers through a CALLBACK_.

WHY THIS FILE MATTERS IN THE SERVER: Clinical entities do not all support the same actions: for example, only Patient and Visits can be deleted, and only Patient supports search and visit lookup. This interface defines the common surface the HTTP layer can rely on, while letting the concrete ClinicController return a clear "not implemented" for unsupported actions. Without it, clinic endpoints would have no uniform contract.
