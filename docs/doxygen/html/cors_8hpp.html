Detailed Description

CORS header helpers applied to every response by the pre-sending advice in server.cpp.

This header provides small functions that write the Cross-Origin Resource Sharing (CORS) headers onto an outgoing HTTP response. CORS is the browser rule that decides whether a web page on one domain may read a response from another domain. The code here reads the configured list of allowed origins, reflects an exact match back with credentials, or falls back to a wildcard or first configured origin. It also handles preflight (OPTIONS) requests by echoing a sanitized list of requested headers.

WHY THIS FILE MATTERS IN THE SERVER: Without these headers, a browser front end served from a different address than the API would be blocked by its same-origin policy, even though the API itself works. server.cpp calls Cors::apply() for every single response, so this file is the one central place that makes the REST API reachable from a web app. It also contains the small token helpers' entry points used by the preflight logic, so CORS behaviour stays consistent and easy to audit.
