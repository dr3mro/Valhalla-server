Detailed Description

A small type that stores permissions as on/off bits in one byte. (Originally: "Holds a bitmask of authorization bits and the helpers to combine/test them.").

This header defines the Permissions struct. It lists the individual rights (like "can read" or "is owner") as single bits, and provides operators to combine and test those bits. A single value can represent several rights at once.

WHY THIS FILE MATTERS IN THE SERVER: Authorization questions ("may this person delete this?") are answered using these bit masks. PermissionManager and PermissionManagerPrivate call the helpers here to turn a number stored in the database into a clear yes/no. Without this file there would be no common language for describing rights.
