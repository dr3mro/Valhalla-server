Detailed Description

RAII lease of a single pooled Database connection.

This header declares DatabaseHanndler (spelled exactly that way in this codebase). Its constructor leases one connection from a DatabaseConnectionPool, waiting up to the configured timeout, and its destructor returns that connection. That makes it a small RAII guard: as long as the handler object lives, the caller owns a valid database connection, and it is released automatically on every exit path.

WHY THIS FILE MATTERS IN THE SERVER: This class is the bridge between the connection pool and the code that actually runs SQL. Controllers and the watchdog create one on the stack per request or health check; they call get_connection() to reach the Database and run queries, then simply let the handler go out of scope. Because returning happens in the destructor, a thrown query exception cannot leak a connection. Without this guard, callers would have to remember to return every lease by hand, and one forgotten path would starve the pool.

CONCEPTS TO LEARN (for beginners):

  • RAII (resource acquisition is initialisation): https://en.cppreference.com/w/cpp/language/raii
  • std::shared_ptr (shared ownership): https://en.cppreference.com/w/cpp/memory/shared_ptr
  • std::move (transferring ownership instead of copying): https://en.cppreference.com/w/cpp/utility/move
  • Stack allocation and object lifetime: https://en.cppreference.com/w/cpp/language/storage_duration
