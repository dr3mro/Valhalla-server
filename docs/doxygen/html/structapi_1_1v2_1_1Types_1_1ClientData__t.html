Detailed Description

Common parsing and field extraction for client-style create/update payloads.

Parses a raw JSON body, records parse errors through error/success, and keeps both the parsed JSON and a flat set of (column, value) pairs used by the Client SQL builders. Password hashing on the flat set is available to subclasses.
