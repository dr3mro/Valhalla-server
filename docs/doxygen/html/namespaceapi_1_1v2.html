static

Dispatch a controller method for a keyed entity type, off the IO thread when needed.

Looks up key in registry (an unordered_map of std::variant controller pointers); a missing key is answered with 400 and no controller is invoked. A model callback (int status + content) is adapted to HTTP responses: OK -> success, INTERNAL_SERVER_ERROR -> failure (500 body), anything else -> error with that numeric status. Requester identity is read from the "clientID"/"clientGroup" attributes that the Auth filter inserts on SECURE routes (INSECURE routes such as client create/login also use this helper). When executor.ioFastPath() is enabled the call is first tried on the IO thread inside a DbProbe: work that needs no connection completes there, whereas the first WouldBlock is caught and the whole call is re-queued on the DB executor from the start. Request, arguments and callback are captured by value because queued work finishes after this function returns on a worker thread. A full executor queue is answered 503 without running the controller; DatabaseBusy becomes 503, and any other std::exception becomes a 500 failure response.

inline

Safely parse a numeric id query parameter, replying 400 on failure.

Calling std::stoll directly on req->getParameter(name) would throw std::invalid_argument or std::out_of_range while building the handler's argument list, i.e. before executeControllerMethod's try/catch is entered; the exception then escaped Drogon's dispatch as a raw, empty-body 500. This helper contains the throw and emits a normal JSON 400 instead. On failure the callback has already been invoked with the error response.

Parameters
[in]reqRequest whose query parameter is read.
[in]nameParameter name to parse as an integer id.
[in,out]callbackResponse callback; invoked with a 400 when parsing fails.
Returns
The parsed id, or std::nullopt on failure (callback already answered).
Postcondition
If std::nullopt is returned the caller must return early without calling executeControllerMethod, otherwise a second response would be sent.
