Detailed Description

Base for configuration sections that read typed values from the process environment.

Extends EnvVars with a family of getEnvironmentVariable() overloads that convert a raw string into the target type and fall back to a caller-supplied default when the variable is absent (or, for numeric/duration types, malformed). Conversion failures are reported through Message::ErrorMessage rather than thrown, so a bad environment cannot prevent startup. Derived classes must implement printValues() and typically call these accessors from their constructor initializer lists.

Note
Numeric overloads parse through std::stoi, so integer values outside the range of a signed int are rejected even when the destination type is wider.
Warning
A present boolean variable equals true only when it is exactly "true"; any other present value is interpreted as false (not as the supplied default).

template<typename T>
T EnvLoader::getEnvironmentVariable ( const std::string & key,
T defaultValue )
inline

Reads an integer-like environment variable, converting with std::stoi.

When the variable is absent the default is returned directly. When present, the value is parsed as a signed int and static_cast to T. A parse failure is logged and the default returned. In plain language: "if the deployment set this variable, try to read it as a whole number; if that fails for any reason, quietly use the safe default."

Template Parameters
TDestination type (typically an unsigned integer or small enum); must be constructible by static_cast from the std::stoi result.
Parameters
[in]keyEnvironment-variable name.
[in]defaultValueValue used when the variable is absent or unparsable.
Returns
The parsed value, or defaultValue.
Note
Because parsing goes through std::stoi, values greater than INT_MAX (or less than INT_MIN) fall back to the default even for 64-bit destinations.
