enum api::v2::Http::Status : uint16_t

HTTP status codes returned as the first CALLBACK_ argument.

Enumerators mirror standard HTTP codes, grouped below by class: 1xx informational, 2xx success, 3xx redirection, 4xx client error and 5xx server error. INTERNAL_SERVER_ERROR and SERVICE_UNAVAILABLE are the two values produced by statusForException.

Note
Only codes used by this server are listed; getDescription falls back to a generic string for values outside this set.

Status api::v2::Http::statusForException ( const std::exception & e)
inline

Selects the HTTP status corresponding to a caught exception.

A DatabaseBusy means no database connection was available, so the client is told 503 and may retry; all other failures are 500. Used by the CRITICALMESSAGERESPONSE macro.

Parameters
[in]eThe caught exception to classify.
Returns
Status::SERVICE_UNAVAILABLE for DatabaseBusy, otherwise Status::INTERNAL_SERVER_ERROR.
Note
Classification uses dynamic_cast, so it relies on the exception being polymorphic (as all std::exception-derived types are).
