Detailed Description

The implementation of login, logout and session bookkeeping. (Originally: "Implementation for sessionmanager: Reads the stored password hash after checking the account exists and is active.").

This file reads a client's stored hash, verifies the supplied password, records login/logout times, and manages the in-memory session cache. Tokens are decoded and compared to the stored session in constant time to stop forged tokens hijacking an account.

WHY THIS FILE MATTERS IN THE SERVER: This is where a username/password becomes a trusted session. GateKeeper calls it for login and logout; the session data it stores is what later requests rely on to know who is calling. Without it, no one could sign in or out.
