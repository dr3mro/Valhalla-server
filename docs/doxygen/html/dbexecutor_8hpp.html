Detailed Description

BoundedExecutor configured for the synchronous database path.

This header declares DbExecutor, a thin subclass of BoundedExecutor that runs blocking database work off the Drogon IO threads. It has two constructors: one takes worker count, queue size and fast-path flag from configuration, the other takes explicit sizes for tests. It also provides runOnDbExecutor(), a helper that submits work and answers 503 itself if the bounded queue is full.

WHY THIS FILE MATTERS IN THE SERVER: Drogon's IO threads must stay free to accept and route HTTP requests; a slow SQL query on one of them would stall every other request. Routes obtain the shared DbExecutor from the Store and call runOnDbExecutor() so permission checks, queries and response building run on dedicated workers. The optional IO-thread fast path (see dbprobe.hpp) lets requests that need no database finish without ever queueing. Without this executor, blocking database work would run on IO threads and the server would grind to a halt under load.

CALLBACK_ && callback,
Body && body )

Submits body to a DbExecutor, answering 503 if it cannot be accepted.

Wraps runOnExecutor with the database-busy message. The callback is shared with the queued task so it remains available for the 503 reply if submission fails. Any database work that must not run on an IO thread belongs in body.
