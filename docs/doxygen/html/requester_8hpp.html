Detailed Description

Caller identity used by the permission layer.

Defines the Requester value object, which carries two pieces of information about who made an API request: an opaque numeric id and a group name. It offers simple getters, setters and matching helpers such as isAdmin() or idMatch(). A GroupId enum lists known groups, but the actual checks compare group names as plain strings.

WHY THIS FILE MATTERS IN THE SERVER: The gatekeeper and permission manager need to know who is calling before they allow an action. Controllers copy a Requester into the work they dispatch to other threads, so the checks still see the original caller's identity. The isX helpers (isAdmin, isProvider, ...) let permission rules read like plain English. Without this object there would be no consistent way to carry caller identity from the HTTP layer down to the permission checks.
