Detailed Description

Implementations of the shared v2 JSON response helpers.

This file contains the bodies of the Helper class functions declared in helper.hpp. Each public function (failureResponse, errorResponse, successResponse) delegates to the private reply function with the right status and body. reply creates a Drogon response, sets the status, JSON content type and body, adds Retry-After for 503, and calls the callback. The prepare function builds a JSON object with a "Status" tag plus the message.

WHY THIS FILE MATTERS IN THE SERVER: This is where the API's response format is actually produced. Every JSON success and error sent by controllers and filters passes through these few functions, so this file guarantees that status codes, content types and headers are set the same way everywhere. It is called by common.hpp, the Auth filter and all route controllers. Without it there would be no central place to enforce a consistent reply format or the retry hint for overloaded servers.

CONCEPTS TO LEARN (for beginners):

  • HTTP status codes: https://developer.mozilla.org/en-US/docs/Web/HTTP/Status
  • The Retry-After header: https://developer.mozilla.org/en-US/docs/Web/HTTP/Headers/Retry-After
  • std::move (transfer ownership instead of copying): https://en.cppreference.com/w/cpp/utility/move
  • CORS (background on HTTP headers): https://developer.mozilla.org/en-US/docs/Web/HTTP/CORS
