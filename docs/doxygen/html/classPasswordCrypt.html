Detailed Description

Thin wrapper around libsodium's password-hashing primitives used by the password workers.

Owns no per-instance state beyond ensuring libsodium is initialized in the constructor. Hashing uses Argon2id at OWASP's minimum recommended cost; verification also accepts hashes produced by the legacy scrypt scheme so existing accounts remain valid. The stored hash is self-describing (algorithm, cost, salt and digest), which is how verifyPassword selects the algorithm without any extra metadata.

In everyday words: a "hash" is a one-way, deliberately slow, scrambled version of a password. We store the hash and never the real password. "Argon2id" and "scrypt" are the names of the recipes used to scramble it. "Self-describing" means the hash string itself records the recipe and the amount of work used, so verification needs no separate note. A "salt" is random data mixed in so two people with the same password still get different hashes.

Warning
The hashes are intentionally expensive; callers must run hashPassword()/verifyPassword() on a PasswordWorker, never on a Drogon IO thread. See runOnPasswordWorker().

PasswordCrypt::PasswordCrypt ( )

Initializes libsodium, reporting a critical error (Message::CriticalMessage) on failure.

Ensures libsodium is initialized before any hashing or verification.

libsodium is a library that must be set up once before any of its functions are used; this constructor does that setup. If setup fails, a critical error is logged but the object is still created, so later password operations will simply fail.

A failed initialization is fatal for password operations and is reported through Message::CriticalMessage; construction still succeeds. In everyday words, libsodium needs a one-time "wake up" call before it can be used; this constructor makes that call and shouts in the log if it fails.

std::optional< std::string > PasswordCrypt::hashPassword ( const std::string & password)

Produces a self-describing Argon2id hash string for password.

Uses a random salt generated by libsodium. The cost parameters are deliberately low enough for the dedicated worker pool but meet OWASP's minimum recommendations. In everyday words: we make a random salt, mix it with the password using the Argon2id recipe, and return one string holding the recipe settings, the salt and the result. "nullopt" means "no value" and is returned when the machine cannot spare the needed memory.

Parameters
[in]passwordPlaintext password to hash.
Returns
The encoded hash string on success, or std::nullopt if libsodium could not allocate the required memory (a critical message is logged in that case).
Note
Safe to call concurrently; no per-instance state is mutated.

Hashes password into a self-describing Argon2id string. In everyday words: ask libsodium to pick a random salt and do the slow mixing, writing a ready-to-store string into a fixed-size buffer. password: Plaintext password. Returns Encoded hash on success; std::nullopt if libsodium could not allocate memory. See also: PasswordCrypt::hashPassword

bool PasswordCrypt::verifyPassword ( const std::string & password,
const std::string & hash )
nodiscard

Verifies password against a stored self-describing hash.

Selects the algorithm from the hash prefix: Argon2id ($argon2...) or the legacy scrypt format ($7$). An unrecognized prefix yields false rather than an exception. In everyday words: the stored hash begins with a short label that says which recipe made it. We read that label, run the matching check, and return true only for a real match. Anything we do not understand is safely treated as a failed login, not a crash.

Parameters
[in]passwordPlaintext password to check.
[in]hashStored hash string produced by hashPassword() or by the legacy scheme.
Returns
true only if the password matches the hash; false on mismatch, unknown algorithm, or malformed hash.

Verifies password against hash, selecting the algorithm from the hash prefix. In everyday words: look at the label at the front of the stored hash to decide which recipe was used, then let libsodium redo the slow mixing and tell us if the result matches. password: Plaintext password. hash: Stored self-describing hash (Argon2id or legacy scrypt). Returns true on a match, false otherwise (including unknown prefixes). See also: PasswordCrypt::verifyPassword
