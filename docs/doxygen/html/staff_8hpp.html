Detailed Description

REST controller for managing staff membership of service entities.

This file defines the Staff controller, which invites, adds and removes staff members of a service entity. The {serviceType} part of the URL (clinics, pharmacies, laboratories or radiologycenters) selects one concrete StaffController from a std::variant registry. Each handler translates the controller's numeric status into a standard JSON HTTP response and builds a Requester from the identity attributes set by Auth. Depending on the configuration it either awaits an async controller coroutine or uses executeControllerMethod for blocking database work. All routes are SECURE.

WHY THIS FILE MATTERS IN THE SERVER: This controller is the HTTP front door for managing who works at each service provider. Drogon routes the /api/v2 staff URLs here; the handlers call the shared dispatcher, which reaches the staff controllers and the database. It depends on the Auth filter for identity and on the service locator for the executor and controllers. Without it there would be no API way to invite or change the staff of a clinic, pharmacy, laboratory or radiology center.
