Detailed Description

Default values for every environment-driven configuration option.

This header declares a set of compile-time constants, grouped by purpose into small namespaces. They are the "fallback" values the configuration system uses whenever an environment variable is not set or cannot be understood. Because they are baked into the binary, they guarantee the server still has sensible, complete settings even on a fresh machine with no configuration at all. A few values are deliberately insecure development placeholders and are meant to be replaced in a real deployment.

WHY THIS FILE MATTERS IN THE SERVER: This is the single source of truth for "what the server does when nobody tells it what to do". Every Configurator section constructor passes one of these constants to EnvLoader as the default, so changing a number here changes the out-of-the-box behaviour everywhere. It also documents, in one place, the expected units and ranges for each setting (seconds, milliseconds, ports). Without it, a missing environment variable would leave settings undefined and startup would fail.

CONCEPTS TO LEARN (for beginners):

  • Environment variables: https://man7.org/linux/man-pages/man7/environ.7.html
  • Fixed-width integer types such as uint32_t: https://en.cppreference.com/w/cpp/types/integer
