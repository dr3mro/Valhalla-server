2 * @file asyncresultmapper.cpp
3 * @brief Implementation for asyncresultmapper: Converts one row into a JSON object using name- and value-based type inference.
4 * @details This file implements the row-to-JSON conversion. For each column it checks whether the value is SQL NULL,
5 * whether the column is a known boolean or identifier field, whether the text looks like JSON, and otherwise
6 * keeps the text as a string. The first-row and all-row helpers simply call the row mapper in a loop or at
7 * index zero.
8 *
9 * WHY THIS FILE MATTERS IN THE SERVER:
10 * Async controller methods receive a Drogon Result and must return JSON to the HTTP layer. This file performs that
11 * translation and deliberately mirrors the older synchronous Database::executeQuery outcomes: nulls stay null, the
12 * active flag is a boolean, ids are numbers, and json/jsonb columns become nested JSON. Because parsing errors are
13 * caught and the raw text is kept, one unusual database value cannot crash a whole list response. Without this file,
14 * the async database path could not produce the same JSON contract that the rest of the API relies on.
15 *
16 * CONCEPTS TO LEARN (for beginners):
17 * - Drogon result sets, rows and fields: https://drogon.docsforge.com/master/database/
18 * - jsoncons JSON values and parsing: https://danielaparker.github.io/jsoncons/
19 * - std::string_view (a cheap, non-owning look at text): https://en.cppreference.com/w/cpp/string/basic_string_view
20 * - C++ exceptions and catch-all handlers: https://en.cppreference.com/w/cpp/language/try_catch
21 * - C++20 coroutines: https://en.cppreference.com/w/cpp/language/coroutines
22 *
23 * @author Amr Osman <dr3mro@gmail.com>
24 * @date 2026-11-16
25 */

43 /**
44 * @brief Converts one row into a JSON object using name- and value-based type inference.
45 * @details Each row gets its own object. Parse failures are swallowed and the raw text is kept, so this function never
46 * throws for a malformed integer or JSON value. Field values are read through their C-string text form.
47 */
48 jsoncons::json mapRow(const drogon::orm::Result& result, drogon::orm::Result::SizeType row)
49 {
50 jsoncons::json object; // A fresh, empty JSON object for this row; nothing from another row can leak into it.
51
52 const auto column_count = result.columns(); // How many columns this result has, so we know how far to walk.
53 for (drogon::orm::Result::RowSizeType i = 0; i < column_count; ++i) // Visit each column exactly once, from left to right; stop after the last column.
54 {
55 const std::string_view field_name = result.columnName(i); // A non-owning view of the column's name, used for comparisons and as the JSON key.
56 const auto field = result[row][i]; // The single cell at (row, column): its value and null flag.
57
58 if (field.isNull()) // SQL NULL must become JSON null, not the string "NULL" or an empty string.
59 {
60 object[std::string(field_name)] = nullptr; // Copy the name into an owning string for the key, then store a JSON null value.
61 continue; // Nothing else can be inferred from a null value, so move on to the next column.
62 }
63
64 const std::string name(field_name); // Own the column name now, so it can be compared and reused as a JSON key safely.
65 const std::string value(field.c_str()); // Read the cell as text; copying it keeps the data valid after the Result is touched again.
66
67 if (name == "active") // The active flag is known to be a boolean, whatever text PostgreSQL used.
68 {
69 // PostgreSQL emits t/f for booleans; accept the common truthy spellings too.
70 object[name] = (value == "t" || value == "true" || value == "1"); // The comparison produces a C++ bool, which jsoncons stores as JSON true or false.
71 }
72 else if (name == "id" || name.ends_with("_id") || name == "appointment_duration" || name == "appointment_payment_amount") // These column names mark values that the API exposes as whole numbers.
73 {
74 // These columns are numbers in the API, but keep the text if it does not parse.
75 try
76 {
77 object[name] = std::stoi(value); // Convert the text to an integer; stoi throws if the text is not a valid number.
78 }
79 catch (...) // Catch every exception type from the conversion, including out-of-range numbers.
80 {
81 object[name] = value; // Fall back to the original text so a single odd value cannot abort the row.
82 }
83 }
84 else if (!value.empty() && (value.front() == '{' || value.front() == '[')) // A value starting with a brace or bracket is probably a JSON object or array.
85 {
86 // json/jsonb arrive as text; a failed parse degrades to a plain string.
87 try
88 {
89 object[name] = jsoncons::json::parse(value); // Parse the text into real nested JSON when it is well formed.
90 }
91 catch (...) // Any parse error is deliberately ignored here.
92 {
93 object[name] = value; // Keep the raw text as a string instead of failing the whole request.
94 }
95 }
96 else // No special rule matched, so this is an ordinary text column.
97 {
98 object[name] = value; // Store the value as a plain JSON string.
99 }
100 }
101
102 return object; // The caller receives one JSON entry per column, in column order.
103 }

105 /**
106 * @brief Maps the first row, using a null JSON value to represent an empty result.
107 * @details The emptiness check also avoids indexing into a result with no rows.
108 */
109 jsoncons::json mapResultToObject(const drogon::orm::Result& result)
110 {
111 if (result.empty()) // A SELECT can legitimately return no rows, e.g. a lookup for a missing id.
112 {
113 return jsoncons::json(); // A default-constructed jsoncons::json is a JSON null, matching the synchronous path.
114 }
115 return mapRow(result, 0); // Row indexes start at zero, so this converts the first (and possibly only) row.
116 }

118 /**
119 * @brief Maps rows sequentially into an array, preserving the query's row order.
120 */
121 jsoncons::json::array mapResultToArray(const drogon::orm::Result& result)
122 {
123 jsoncons::json::array reply; // Empty array that will hold one JSON object per row.
124
125 for (drogon::orm::Result::SizeType row = 0; row < result.size(); ++row) // Walk rows from first to last; stop when every row has been converted.
126 {
127 reply.push_back(mapRow(result, row)); // Convert the row and append it, keeping the database's order intact.
128 }
129 return reply; // An empty result simply produces an empty array, which is what list endpoints return.
130 }
