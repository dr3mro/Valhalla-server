Detailed Description

A dedicated thread pool for the slow work of hashing and checking passwords. (Originally: "The pool for deliberately slow password work (hashing and verification), so it never runs on a Drogon IO thread.").

This header declares a small class that is really just a named BoundedExecutor for password jobs, plus a helper that submits a job to it. Password work is deliberately slow, so it must not run on the threads that handle web requests.

WHY THIS FILE MATTERS IN THE SERVER: Login and registration need password hashing, which is intentionally expensive. If that ran on a Drogon IO thread, one login would freeze request handling for everyone. GateKeeper uses this pool to keep password work separate; without it the server would be slow and vulnerable to login-based denial of service.

template<typename Body>
void runOnPasswordWorker ( PasswordWorker & worker,
CALLBACK_ && callback,
Body && body )

Runs body on worker, answering the callback with 503 if the queue is full.

The callback is shared with the queued task so it remains valid for the busy reply; in that case body never executes. See runOnExecutor() for the full contract. In everyday words: try to put this job on the password pool. If the queue is full, immediately answer the client with HTTP 503 ("try again soon") instead of making them wait forever.
