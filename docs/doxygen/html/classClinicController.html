Detailed Description

template<typename T>
class ClinicController< T >

Clinic-entity handler that specializes generic CRUDS behaviour per entity type via constrained helpers.

Inherits persistence from EntityController<T> and the clinic contract from ClinicControllerBase. Public methods are thin forwarders to private ...Impl overloads selected by C++20 requires clauses. This lets the controller distinguish, for example, Patient/Visits (which use server-assigned ids and support Delete) from other clinic entities (which carry a client-supplied id and reject Delete/Search/GetVisits).

Template Parameters
TClinic entity type; the constraints inside each helper decide which specialization applies.
Note
All public overrides are final. Coroutine variants borrow their arguments and must be awaited while alive.
See also
ClinicControllerBase, EntityController
