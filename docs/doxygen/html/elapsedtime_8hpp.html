Detailed Description

Timing middleware that logs how long a request took to produce its response.

This file defines the ElapsedTime middleware, used in both the INSECURE and SECURE chains. When a request arrives it records a start time using a steady clock. It then passes the request down the chain and installs a callback that runs on the way back out, when the downstream handler has produced its response. That callback measures the elapsed milliseconds and writes a coloured log line containing the time, client IP, HTTP method, status code and path, then forwards the response unchanged.

WHY THIS FILE MATTERS IN THE SERVER: This middleware is the server's stopwatch. It is the only place that reports how long each endpoint actually took, which is how developers spot slow routes or database bottlenecks. It sits around the rest of the chain, so it measures the full cost of rate limiting, authentication and the handler. It changes nothing about the response; without it the server would still work but you would be blind to performance problems.
