Detailed Description

Case entity for the patients table; the patient record owned by a clinic.

This header declares the Patient class, a small C++ type that stands for one patient in the patients database table. A patient belongs directly to a clinic, so this class stores the clinic id in a create payload and checks it directly against the clinics table. It holds no data of its own; it names the table and leaves SQL generation to its parent Case. It is also the only case entity that builds a "get visits" query, and it supplies permission-checking SQL helpers for create, read, update and delete.

WHY THIS FILE MATTERS IN THE SERVER: Patient is a central clinic-owned "case" type exposed through the clinic routes as ClinicController<Patient> under the patients service type; those routes also cover search and getvisits. When a client adds or changes a patient, PermissionManager uses the static getPermissionsQueryFor* helpers here to confirm the requester belongs to the clinic named in the payload. The GetVisits helpers return the SQL that lists a patient's visits, used by the visits feature. Without this file there would be no C++ type connecting the patients table to the CRUD, permission and visits machinery, so patient and visit endpoints could not work.

CONCEPTS TO LEARN (for beginners):

  • static constexpr: a value fixed at compile time that belongs to the class, not to one object. https://en.cppreference.com/w/cpp/language/static
  • JSON: a text format used to carry request data; this project uses the jsoncons library to read it. https://jsoncons.github.io/jsoncons/
  • = delete: explicitly forbidding an operation such as copying, so the compiler rejects it with a clear error. https://en.cppreference.com/w/cpp
