Detailed Description

Exception signalling that the connection pool could not lease a connection in time.

Distinguishes pool exhaustion from a genuine query failure so the HTTP layer can map it to 503 (Service Unavailable) with Retry-After rather than 500. Derives from std::runtime_error so generic handlers still catch it.

See also
api::v2::Http::statusForException, DatabaseConnectionPool::get_connection
