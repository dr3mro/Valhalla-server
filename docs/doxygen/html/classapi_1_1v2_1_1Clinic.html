Detailed Description

REST controller for clinic-related services (patients, visits and visit documents).

A {serviceType} path segment selects a ClinicController<T> from a variant registry (patients, visits, visitDrugs, requests, prescriptions, paidservices, reports, patientdrugs, health). Search and GetVisits are hard-coded to the "patients" controller. Handlers use the shared callback pattern to map controller status codes to JSON HTTP responses, build a Requester from Auth attributes, and run async coroutines or the DbExecutor-backed dispatch according to DatabaseConfig::async. All routes are SECURE.
