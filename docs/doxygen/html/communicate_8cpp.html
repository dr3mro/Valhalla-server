Detailed Description

Implementation for communicate.

Implements Communicate::sendRequest, which allocates a cURL handle and header list, builds the URL, chooses GET or POST through a small lookup table of lambdas, performs the transfer and cleans up. handleResponse registers WriteCallback so incoming bytes are appended to a string, and WriteCallback does that append. Failures are logged and returned as empty optionals instead of thrown exceptions.

WHY THIS FILE MATTERS IN THE SERVER: This is where the actual outbound HTTP work happens. Callers get a simple "send this request, give me the body" interface while all the messy libcurl setup, method selection, resource cleanup and error logging stay here. Because every failure is converted to std::nullopt, callers do not need try/catch blocks of their own. Without this file the service-to-service calling code would have to be repeated and carefully cleaned up at every call site.

CONCEPTS TO LEARN (for beginners):

  • libcurl easy API: https://curl.se/libcurl/c/curl_easy_init.html
  • std::function: https://en.cppreference.com/w/cpp/utility/functional/function
  • Lambdas with captures ([&curl, &data]): https://en.cppreference.com/w/cpp/language/lambda
  • std::optional::value_or: https://en.cppreference.com/w/cpp/utility/optional/value_or
