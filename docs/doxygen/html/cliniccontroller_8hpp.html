Detailed Description

Clinic-entity handler that specializes generic CRUDS behaviour per entity type via constrained helpers.

Declares ClinicController<T>, which inherits storage from EntityController<T> and the clinic contract from ClinicControllerBase. Public methods are thin forwarders to private ...Impl helpers; each helper has a C++20 requires clause so the compiler picks the right behaviour for the concrete entity type. For example, Patient/Visits use server-assigned ids and support Delete, while other types carry a client id and get a "not implemented" answer for Delete/Search/GetVisits.

WHY THIS FILE MATTERS IN THE SERVER: Clinic data has type-specific rules that a single generic handler cannot express cleanly. This class centralizes those rules using compile-time constraints, so the public API stays uniform while the correct behaviour is chosen automatically for each entity. Without it, every clinic handler would need hand-written special cases.
