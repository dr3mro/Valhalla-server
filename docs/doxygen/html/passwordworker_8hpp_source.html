1/**
2 * @file passwordworker.hpp
3 * @brief A dedicated thread pool for the slow work of hashing and checking passwords.
4 * (Originally: "The pool for deliberately slow password work (hashing and verification), so it never runs on a Drogon IO thread.")
5 * @details This header declares a small class that is really just a named
6 * BoundedExecutor for password jobs, plus a helper that submits a job
7 * to it. Password work is deliberately slow, so it must not run on the
8 * threads that handle web requests.
9 *
10 * WHY THIS FILE MATTERS IN THE SERVER:
11 * Login and registration need password hashing, which is intentionally expensive.
12 * If that ran on a Drogon IO thread, one login would freeze request handling for
13 * everyone. GateKeeper uses this pool to keep password work separate; without it
14 * the server would be slow and vulnerable to login-based denial of service.
15 *
16 * CONCEPTS TO LEARN (for beginners):
17 * - Thread pools: https://en.wikipedia.org/wiki/Thread_pool
18 * - C++ threads: https://en.cppreference.com/w/cpp/thread/thread
19 * - HTTP 503 (server busy): https://developer.mozilla.org/en-US/docs/Web/HTTP/Status/503
20 * - Perfect forwarding (std::forward): https://en.cppreference.com/w/cpp/utility/forward
21 *
22 * @author Amr Osman <dr3mro@gmail.com>
23 * @date 2026-11-16
24 */

35 * @class PasswordWorker
36 * @brief The pool for deliberately slow password work (hashing and verification), so it never runs on a Drogon IO thread.
37 * @details Keeping password operations off the IO threads prevents them from blocking request
38 * handling. Queueing, fair dispatch, zero-worker inline mode and shutdown semantics
39 * are inherited from BoundedExecutor; see that class for the queue and inline-mode rules.

58/**
59 * @brief Runs @p body on @p worker, answering the callback with 503 if the queue is full.
60 * @details The callback is shared with the queued task so it remains valid for the busy reply;
61 * in that case @p body never executes. See runOnExecutor() for the full contract.
62 * In everyday words: try to put this job on the password pool. If the
63 * queue is full, immediately answer the client with HTTP 503 ("try
64 * again soon") instead of making them wait forever.
65 * @tparam Body Callable invoked with a moved CALLBACK_ on a worker thread.
66 * @param[in,out] worker Pool that executes @p body.
67 * @param[in,out] callback Request callback moved into the task (or used for the 503 reply).
68 * @param[in,out] body Work to run on the password worker.
69 */
70template <typename Body>
71void runOnPasswordWorker(PasswordWorker& worker, CALLBACK_&& callback, Body&& body) // Submits a password job to the pool.
72{
73 // Hand off to the generic helper with a password-specific "busy" message. std::forward keeps the job's value category intact.
74 runOnExecutor(worker, std::move(callback), "Too many password operations in progress, try again shortly.", std::forward<Body>(body)); // The real work of queueing and replying.
75}
