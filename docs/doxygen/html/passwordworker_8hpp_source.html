1/**
2 * @file passwordworker.hpp
3 * @brief A dedicated thread pool for the slow work of hashing and checking
4 * passwords. (Originally: "The pool for deliberately slow password work
5 * (hashing and verification), so it never runs on a Drogon IO thread.")
6 * @details This header declares a small class that is really just a named
7 * BoundedExecutor for password jobs, plus a helper that submits a job
8 * to it. Password work is deliberately slow, so it must not run on the
9 * threads that handle web requests.
10 *
11 * WHY THIS FILE MATTERS IN THE SERVER:
12 * Login and registration need password hashing, which is intentionally
13 * expensive. If that ran on a Drogon IO thread, one login would freeze request
14 * handling for everyone. GateKeeper uses this pool to keep password work
15 * separate; without it the server would be slow and vulnerable to login-based
16 * denial of service.
17 *
18 * CONCEPTS TO LEARN (for beginners):
19 * - Thread pools: https://en.wikipedia.org/wiki/Thread_pool
20 * - C++ threads: https://en.cppreference.com/w/cpp/thread/thread
21 * - HTTP 503 (server busy):
22 * https://developer.mozilla.org/en-US/docs/Web/HTTP/Status/503
23 * - Perfect forwarding (std::forward):
24 * https://en.cppreference.com/w/cpp/utility/forward
25 *
26 * @author Amr Osman <dr3mro@gmail.com>
27 * @date 2026-11-16
28 */

72/**
73 * @brief Runs @p body on @p worker, answering the callback with 503 if the
74 * queue is full.
75 * @details The callback is shared with the queued task so it remains valid for
76 * the busy reply; in that case @p body never executes. See runOnExecutor() for
77 * the full contract. In everyday words: try to put this job on the password
78 * pool. If the queue is full, immediately answer the client with HTTP 503 ("try
79 * again soon") instead of making them wait forever.
80 * @tparam Body Callable invoked with a moved CALLBACK_ on a worker thread.
81 * @param[in,out] worker Pool that executes @p body.
82 * @param[in,out] callback Request callback moved into the task (or used for the
83 * 503 reply).
84 * @param[in,out] body Work to run on the password worker.
85 */
86// Submits a password job to the pool.
87template <typename Body>
88void runOnPasswordWorker(PasswordWorker& worker,
89 CALLBACK_&& callback,
90 Body&& body) {
91 // Hand off to the generic helper with a password-specific "busy" message.
92 // std::forward keeps the job's value category intact.
93 runOnExecutor(worker,
94 std::move(callback),
95 "Too many password operations in progress, try again shortly.",
96 std::forward<Body>(
97 body)); // The real work of queueing and replying.
98}
