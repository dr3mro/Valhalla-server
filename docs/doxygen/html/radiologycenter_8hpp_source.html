1/**
2 * @file radiologycenter.hpp
3 * @brief Appointment entity bound to the radiologycenters organisation and its
4 * appointment table.
5 * @details This is a thin concrete specialisation of Appointment. It fixes the
6 * table name
7 * ("radiologycenters_appointments") and organisation name ("radiologycenters"),
8 * forwards a payload to the base constructor, and exposes two static
9 * permission-query helpers by calling the shared Appointment implementations.
10 * It adds no state or logic of its own.
11 *
12 * WHY THIS FILE MATTERS IN THE SERVER:
13 * Controllers that work with radiology-centre appointments construct this class
14 * so the generic Appointment code is tied to the right table and organisation.
15 * PermissionManager calls its two static helpers to authorise appointment
16 * actions. Without it, the shared permission logic would have no
17 * radiology-centre-specific table and organisation names to work with.
18 *
19 * CONCEPTS TO LEARN (for beginners):
20 * - std::optional: https://en.cppreference.com/w/cpp/utility/optional
21 * - Static constexpr member: a compile-time constant stored on the class,
22 * usable without an object.
23 * - Inheritance: deriving from Appointment means this class automatically gets
24 * its CRUD builders.
25 *
26 * @author Amr Osman <dr3mro@gmail.com>
27 * @date 2026-11-16
28 */
