1/**
2 * @file visitdrugs.hpp
3 * @brief Case entity for the `patients_visitdrugs` table (drugs recorded for a visit).
4 * @details This header declares the VisitDrugs class, a small C++ type that stands for the drugs recorded for one visit
5 * in the `patients_visitdrugs` database table. Despite the table name starting with `patients_`, ownership is
6 * resolved through the visit (the create payload carries a visit id). The class itself holds no data; it names
7 * the table and leaves SQL generation to its parent Case. It also supplies small helper functions that build
8 * permission-checking SQL for create, read, update and delete operations.
9 *
10 * WHY THIS FILE MATTERS IN THE SERVER:
11 * VisitDrugs is one of the clinic-owned "case" types exposed through the clinic routes as ClinicController<VisitDrugs>
12 * under the `visitDrugs` service type. When a client wants to add or change a visit's drugs, PermissionManager calls the
13 * static getPermissionsQueryFor* helpers here to build a SELECT that finds which clinic owns the visit (via
14 * `clinics_visits`), then checks whether the requesting user is that clinic's owner, admin or staff. Without this file
15 * there would be no C++ type connecting the `patients_visitdrugs` table to the CRUD and permission machinery, so
16 * visit-drug endpoints could not work.
17 *
18 * CONCEPTS TO LEARN (for beginners):
19 * - static constexpr: a value fixed at compile time that belongs to the class, not to one object. https://en.cppreference.com/w/cpp/language/static
20 * - JSON: a text format used to carry request data; this project uses the jsoncons library to read it. https://jsoncons.github.io/jsoncons/
21 * - Foreign key: a column that points to a row in another table, used here to trace a record back to its owning visit
22 * and then to the owning clinic. https://en.cppreference.com/w/cpp
23 *
24 * @author Amr Osman <dr3mro@gmail.com>
25 * @date 2026-11-16
26 */
