Detailed Description

template<Appointment_t T>
class AppointmentController< T >

Appointment-entity controller that adapts EntityController to AppointmentControllerBase.

Template Parameters
TAppointment entity type; must satisfy Appointment_t (derived from Appointment).

A thin, stateless adapter: each CRUD+S entry point forwards to the same-named method of EntityController<T>. Schema validation, permission checks, entity construction, SQL execution, JSON marshalling and error→HTTP mapping are therefore inherited rather than reimplemented here; T supplies the table name, SQL statements and permission queries. The distinct base interface lets the appointments route registry select appointment controllers independently of service controllers.

Plain-language version: T is whichever appointment class we are handling (say ClinicAppointment). The Appointment_t after template is a "concept" — a compile-time check that refuses to build this class unless T is really an appointment type. Because this class stores no data ("stateless"), its only job is to hand the arguments to EntityController<T> and let that base do everything.

Explicit instantiations exist for ClinicAppointment, PharmacyAppointment, LaboratoryAppointment and RadiologyCenterAppointment.

Note
Copy and move are permitted, matching the value semantics of EntityController; the route registry nonetheless holds controllers as shared pointers.
