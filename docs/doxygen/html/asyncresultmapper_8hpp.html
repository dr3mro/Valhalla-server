Detailed Description

Maps Drogon PostgreSQL result sets to jsoncons values with the outcomes of the synchronous path in mind.

This header declares functions that convert query results into JSON. One function converts a single row into a JSON object, and two helpers wrap that for the common cases of "first row only" and "all rows as an array". Column names and the value text decide the JSON type: nulls stay null, a boolean flag becomes true/false, identifier columns become numbers, JSON-looking text is parsed, and everything else is a string.

WHY THIS FILE MATTERS IN THE SERVER: DatabaseController's coroutine methods return JSON to the HTTP layer, but Drogon gives them a Result set of rows and fields. These functions are the translation step in between. They deliberately reproduce the behaviour of the older synchronous Database::executeQuery so clients cannot tell which database path answered their request. A malformed number or JSON value falls back to plain text instead of failing the whole request, which keeps one bad database row from breaking an entire API response. Without this file the async controllers would have no way to produce the JSON shapes the rest of the server expects.
