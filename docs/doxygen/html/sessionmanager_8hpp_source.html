1/**
2 * @file sessionmanager.hpp
3 * @brief The login/logout flow and the in-memory store of active sessions.
4 * (Originally: "Owns the client login flow and the in-memory session cache.")
5 * @details This header declares SessionManager. It splits logging in into two
6 * steps so the slow password check can run on a worker thread, and it
7 * keeps active sessions in a shared in-memory cache. Sessions are
8 * identified by a "<group>_<id>" key and carry an expiry time.
9 *
10 * WHY THIS FILE MATTERS IN THE SERVER:
11 * GateKeeper calls this class on every login and logout request. It is the
12 * bridge between credentials (username/password) and a valid session/token.
13 * Without it, the server could neither prove who a user is nor remember that
14 * they are already logged in.
15 *
16 * CONCEPTS TO LEARN (for beginners):
17 * - Sessions vs tokens: https://en.wikipedia.org/wiki/Session_(computer_science)
18 * - Timing attacks (why token comparison is constant-time): https://en.wikipedia.org/wiki/Timing_attack
19 * - C++ shared_ptr (shared ownership): https://en.cppreference.com/w/cpp/memory/shared_ptr
20 * - JWT: https://jwt.io/introduction
21 *
22 * @author Amr Osman <dr3mro@gmail.com>
23 * @date 2026-11-16
24 */

44 /**
45 * @class SessionManager
46 * @brief Owns the client login flow and the in-memory session cache.
47 * @details Login is deliberately split into fetchPasswordHash() (database reads, account
48 * activation check) and completeLogin() (password verification, then login-time
49 * write). GateKeeper invokes the two parts separately so the expensive password
50 * check can run on a PasswordWorker; a wrong password therefore never updates the
51 * stored login time. Sessions live in a shared MemCache keyed by `"<group>_<id>"`
52 * and carry an expiry. All operations report failures through a human-readable
53 * message (or a callback for logout).
54 * @see KeeprBase
55 * In everyday words: logging in is like showing ID at a desk. First we look
56 * up your account and check it is active; then we check your password; only
57 * then do we record that you logged in and hand you a session.
58 */
