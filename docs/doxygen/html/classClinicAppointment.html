Detailed Description

Appointment entity bound to the clinics organisation and its appointment table.

Appointment entity defined in this header, bound to the clinics appointment table.

A thin concrete specialisation of Appointment: it fixes TABLENAME and ORGNAME and forwards the two permission-query requests to the shared base implementations.

See also
Appointment

A minimal Appointment specialisation fixing only TABLENAME and exposing getTableName(); it does not define an organisation name or the static permission-query helpers found in the other appointment specialisations.

Note
The class name collides with ClinicAppointment in entities/appointments/clinic.hpp.
