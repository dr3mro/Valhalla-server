Detailed Description

RAII marker that puts the current thread in "probe" mode.

While an instance is alive, DbProbe::check() throws WouldBlock on that thread, preventing any database access from running on a Drogon IO thread. The active flag is thread_local, so only the constructing thread is affected. Instances are stack-allocated within a try block in the request wrapper and must not be shared across threads. Non-copyable and non-assignable.

Note
The destructor unconditionally clears the flag; nested probes on the same thread would clear it early, so usage assumes a single probe per thread at a time.
