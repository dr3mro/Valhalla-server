Detailed Description

Implementation for keeprbase: Maps a client group to its session table via a fixed allowlist.

This file implements the shared SQL and JWT helpers used by the session and token managers. It chooses a session table from a hard-coded allowlist of the two valid groups (users and providers), then builds parameterized SQL to read or update login/logout times and to load password hashes. It also formats UTC timestamps, extracts identity claims from decoded JWTs, checks them against live session state, and builds an HS256 verifier bound to the configured secret. Most helpers have a coroutine twin that awaits the database read instead of blocking a thread.

WHY THIS FILE MATTERS IN THE SERVER: This is the persistence and token-verification engine under the gatekeeper. SessionManager and TokenManager call these helpers during login, logout and every token check; those managers are called by GateKeeper, which is called by controllers and filters. Crucially, mapping a group to a table through an allowlist (instead of pasting user input into SQL) prevents SQL injection, and parameterized queries keep the actual values safe too. Without this file the managers would have no way to record logouts or decide whether an old token has been invalidated.
