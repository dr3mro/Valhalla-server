1/**
2 * @file requester.hpp
3 * @brief Caller identity used by the permission layer.
4 * @details Defines the Requester value object, which carries two pieces of
5 * information about who made an API request: an opaque numeric id and a
6 * group name. It offers simple getters, setters and matching helpers such
7 * as isAdmin() or idMatch(). A GroupId enum lists known groups, but the
8 * actual checks compare group names as plain strings.
9 *
10 * WHY THIS FILE MATTERS IN THE SERVER:
11 * The gatekeeper and permission manager need to know who is calling before they
12 * allow an action. Controllers copy a Requester into the work they dispatch to
13 * other threads, so the checks still see the original caller's identity. The
14 * isX helpers (isAdmin, isProvider, ...) let permission rules read like plain
15 * English. Without this object there would be no consistent way to carry caller
16 * identity from the HTTP layer down to the permission checks.
17 *
18 * CONCEPTS TO LEARN (for beginners):
19 * - Classes and access specifiers (public/private): https://en.cppreference.com/w/cpp/language/access
20 * - special member functions (= default / = delete): https://en.cppreference.com/w/cpp/language/member_functions#Special_member_functions
21 * - [[nodiscard]] attribute: https://en.cppreference.com/w/cpp/language/attributes/nodiscard
22 *
23 * @author Amr Osman <dr3mro@gmail.com>
24 * @date 2026-11-16
25 */

34 * @struct Requester
35 * @brief Value object describing who issued a request.
36 * @details Holds an opaque numeric id and a group name. It is copied into
37 * lambdas dispatched to worker threads and consulted by the
38 * permission manager, so instances are cheap value types with
39 * defaulted copy/move operations.
40 * @note Group checks are literal string comparisons against hardcoded names
41 * such as "admins", "users", "providers", "staff" and "owners"
