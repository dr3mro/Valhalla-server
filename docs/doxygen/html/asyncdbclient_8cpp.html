Detailed Description

Implementation for asyncdbclient: Stores the supplied client, sharing ownership with the caller.

This file turns the declarations in asyncdbclient.hpp into working code. The constructor simply takes ownership of a ready-made Drogon client; the factory reads the database settings from the Store, asks Drogon to build a PostgreSQL client and sets its execution timeout; the last function formats those settings into the text string that PostgreSQL's client library understands.

WHY THIS FILE MATTERS IN THE SERVER: This is where the asynchronous database client is actually created. During startup Server::run() calls AsyncDbClient::createClient() when DB_ASYNC is enabled, so this file decides which host, port, database, user, password and SSL mode the server connects with, and how large the connection pool is. Every async query made by the database controllers ultimately goes through the client built here. Without it, the Store would have no client to hand to the controllers and every DB_ASYNC request would report the database as unavailable.

  • fmt string formatting: https://fmt.dev/
  • PostgreSQL connection strings: https://www.postgresql.org/docs/current/libpq-connect.html#LIBPQ-CONNSTRING
