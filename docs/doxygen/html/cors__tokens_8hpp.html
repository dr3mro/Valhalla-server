Detailed Description

Drogon-free helpers for parsing and merging CORS header token lists.

This header contains small functions for working with comma-separated header values used by CORS. It can tell whether a character is legal in an HTTP token, trim and split a header value into tokens, compare strings without regard to ASCII case, sanitize a client-supplied header list, and merge a token into an existing Vary header without duplicating it. The helpers deliberately avoid depending on Drogon.

WHY THIS FILE MATTERS IN THE SERVER: These functions are the security and correctness layer behind the CORS code in cors.hpp. When a browser sends an Access-Control-Request-Headers value, this file filters out dangerous characters (such as CRLF or quotes) before they are echoed into a response, preventing header-injection attacks. It also keeps the Vary header tidy so caches store separate responses for different origins. Because the helpers have no framework dependency, they can be tested on their own, which is why a dedicated test file exists for them.
