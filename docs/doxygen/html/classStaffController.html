Detailed Description

template<typename T>
class StaffController< T >

Implements staff management for one service entity type.

Template Parameters
TService entity type (e.g. Clinics); no concept constraint is declared, but the implementation relies on T constructing from api::v2::Types::StaffData and on T::getSqlAddStaffStatement / T::getSqlRemoveStaffStatement being available through Controller.

Unlike ServiceController this is not an EntityController: it inherits Controller for the low-level add/remove-staff SQL helpers and implements the domain operations of StaffControllerBase directly. Each operation parses the request body, obtains a GateKeeper staff-management decision, and only then performs a side effect (an SQL statement, or an HTTP POST to the email-sender daemon for invites). 

     Plain-language version: `T` is the concrete entity (say `Clinics`).

The class relies on T being constructible from staff data and on T providing the add/remove staff SQL statements; those are compile-time expectations rather than an enforced concept. The three jobs here do real work (parse, check permission, act), unlike the pure forwarding service controllers. 

     Explicit instantiations exist for `Clinics`, `Pharmacies`,

Laboratories and RadiologyCenters; the staff route registry stores instances as shared pointers and selects one by service name.

Note
Instances are shared across Drogon workers; the cached dependencies below are populated in the constructor and are not mutated by the operations.
See also
StaffControllerBase, Controller, GateKeeper, Configurator

Adds a staff member described by data to the service entity identified in that body.

Parses payload/id, constructs api::v2::Types::StaffData and T, checks canManageStaff, then delegates to Controller::addStaff. A parse failure is an exceptional 500 path; an authorisation failure returns the GateKeeper error code.

Parameters
[in,out]callbackCompletion handler, invoked once with (status, body).
[in]requesterAuthenticated caller used for the staff-management permission check.
[in]dataRaw JSON body containing id and payload.

Adds a staff member described by data to the service entity it names. Parses a JSON body with payload and id, builds StaffData and T, checks staff-management permission against the id, and finally delegates the SQL work to Controller::addStaff. On denial the GateKeeper's code and message are returned verbatim; any thrown exception is mapped by CRITICALMESSAGERESPONSE (500, or 503 for a busy database). Note: There is no pre-parse guard: malformed JSON or a missing key is an exceptional 500 path here, unlike the 400 responses of EntityController. callback: Completion handler invoked once with (status, body). requester: Authenticated caller used for the staff-management permission check. data: Raw JSON body containing id and payload; must outlive the call.

Invites a staff member by handing an invite message to the email-sender daemon.

Parses nominee_id and api::v2::Types::StaffData, checks canManageStaff, builds the invite JSON and POSTs it via Communicate::sendRequest. Reports 200 with the daemon's body on delivery, 400 when invite construction or delivery fails.

Parameters
[in,out]callbackCompletion handler, invoked once with (status, body).
[in]requesterAuthenticated caller used for the staff-management permission check.
[in]dataRaw JSON body containing nominee_id and the invite fields.

Invites a staff member by handing an invite message to the email-sender daemon. Parses nominee_id and the StaffData fields from the whole body, checks staff-management permission, and — if the fields parsed and the invite JSON could be built — POSTs that JSON to the configured email daemon. The daemon's body is relayed with 200 on success; 400 is returned when invite construction or delivery fails. Note: nominee_id is the value passed to canManageStaff as the permission-check target; note also that the email request is a synchronous cURL call. callback: Completion handler invoked once with (status, body). requester: Authenticated caller used for the staff-management permission check. data: Raw JSON body containing nominee_id and the invite fields.
