Detailed Description

Implementation for dbexecutor: Builds the executor from configuration, naming it "DB executor" for diagnostics.

This file implements the two DbExecutor constructors. Both forward the worker, queue and name settings to the BoundedExecutor base and store the IO fast-path flag. The default constructor reads every setting from the application-wide Configurator; the other takes explicit values, which keeps unit tests independent of configuration.

WHY THIS FILE MATTERS IN THE SERVER: It is the small piece that turns configured numbers into the actual worker pool used for all blocking database work. The "DB executor" label passed to the base class shows up in logs and statistics, so operators can tune worker counts and queue sizes. Without these constructors the DbExecutor declared in the header could not be created, and routes would have nowhere to send blocking queries.
