Detailed Description

Owning aggregate of all runtime configuration sections.

Holds one instance per configuration domain (server, database, DoS detection, tokens, frontend, email sender, caches and workers) plus a testing section. Every section derives from EnvLoader and reads its values from the process environment in its constructor, falling back to the constants in the Defaults namespace when a variable is absent or invalid. The Configurator is intended to be a single process-wide object owned by Store and fully constructed before the Drogon IO threads start; sections are retrieved by type through get<T>().

Note
Values are snapshotted at construction time, so later changes to the environment do not affect an already-built Configurator.
Warning
get() returns a non-const reference and performs no locking. Treat sections as read-only once construction is complete; unsynchronized concurrent mutation is unsafe.
See also
EnvLoader, Defaults, Store

◆ printValues()

void Configurator::printValues ( ) const
inline

Logs the values of the nine non-test configuration sections.

Delegates to each section's printValues(). Secret-bearing fields (database password, token secret) are logged as "[redacted]"; the token secret additionally triggers a warning while it still equals the shipped default. The test-only Testing section is deliberately not printed.

Note
Diagnostic output only; no validation or mutation is performed.
