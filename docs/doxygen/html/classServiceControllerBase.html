Detailed Description

Type-erased interface for service-entity (clinic, pharmacy, laboratory, radiology center) CRUD+S operations.

Declares both a synchronous, callback-driven form of every operation and a coroutine (drogon::Task<void>) form. The HTTP layer reaches concrete controllers through this base via a std::variant in the services route registry, so virtual dispatch here is what makes one route handler serve all service entity types. 

     In plain words: "synchronous" means the caller gets the answer

through a callback function; "coroutine" (drogon::Task<void>) means the caller can pause the operation with co_await and let the server do other work meanwhile. "Virtual dispatch" means that when the route code calls Create through this base type, C++ automatically runs the version belonging to the real object (for example the clinic controller). A std::variant is a variable that can hold one of several different types — here it holds whichever concrete service controller was selected. 

     Invocation contract shared by every method:
     - `callback` is `std::function<void(int, const std::string&)>`,

moved by the caller and forwarded down the call chain. By contract it is invoked once on each completion path, including failures; the first argument is an api::v2::Http::Status code, the second a response body (serialized row(s) on success, diagnostic text on failure).

  • requester is the authenticated caller identity, used by implementations for the permission decision before any database work is done.
  • data is a non-owning view of the raw JSON request body; it must outlive the call.
  • _id, where present, is the optional target entity id; a missing value is rejected by the concrete implementation rather than by this interface. 
         The `*Async` methods perform the same operation but must be
    co_awaited; the route layer wraps them in drogon::async_run and converts the callback result into an HTTP reply.
    Note
    Implementations here are supplied by ServiceController; the interface itself adds no state.
    See also
    ServiceController, EntityControllerBase, Controller
