Detailed Description

template<typename T>
class EntityController< T >

Generic request-facing CRUDS handler: validates and authorizes a request, then delegates persistence to Controller.

Combines the persistence engine (Controller) with the abstract CRUDS interface (EntityControllerBase). Each operation follows the same pipeline: parse/validate the JSON body against the entity's database schema, ask GateKeeper whether requester may perform the action, construct the entity from the appropriate Types data carrier, and call the matching Controller method (or its coroutine counterpart). Failure at any stage answers through callback and returns early, so no database connection is taken for a request that fails validation or authorization.

Template Parameters
TEntity type whose static getTableName() and data-carrier constructors (Create_t/Read_t/Update_t/ Delete_t/Search_t) define the schema used for validation and persistence.
Note
All operations are override implementations of EntityControllerBase. Coroutine variants borrow their arguments and must be awaited while those arguments (and the controller) remain alive.
See also
EntityControllerBase, Controller, GateKeeper
