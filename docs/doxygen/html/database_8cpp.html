Detailed Description

Implementation for database: Takes ownership of a connection, validates it and caches its connection string.

This file implements every helper declared in database.hpp. The constructor opens and validates the connection, checkExists()/executeQuery()/doSimpleQuery() run SQL, check_connection() probes the link, reconnect() rebuilds it, and getTableSchema() / getAllTables() read catalog metadata. Failures are logged and turned into "empty" return values rather than being allowed to crash the server.

WHY THIS FILE MATTERS IN THE SERVER: This is where the synchronous database path actually touches PostgreSQL. Controllers reach it through a DatabaseHanndler lease obtained from DatabaseConnectionPool, and the watchdog uses check_connection()/reconnect() here to keep links healthy. The template functions at the bottom are explicitly instantiated so other translation units can call them. Without this file the declarations in database.hpp would have no implementation and linking would fail, so no blocking database query could run.
