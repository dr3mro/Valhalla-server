Detailed Description

Compile-time fallback values used when a configuration environment variable is absent or cannot be parsed.

Every nested namespace groups the defaults for one Configurator section. These constants are baked into the binary, not read from a file; deployment overrides come from the environment via EnvLoader. Several entries are deliberately insecure development placeholders (database password, token secret, wildcard CORS) and must be overridden in production.
