Detailed Description

Maps exceptions from the Drogon async database path to the HTTP statuses of the synchronous path.

Adapter between the pqxx::params produced by entity SQL builders and Drogon's incremental SQL binder.

Maps Drogon PostgreSQL result sets to jsoncons values with the outcomes of the synchronous path in mind.

An exhausted pool or timeout is "busy" and maps to 503, matching DatabaseBusy; every other failure maps to 500. The helpers take std::exception because coroutine awaits surface their failures through that base type.

SQL nulls become JSON null; the active flag becomes a boolean; identifier-like columns become numbers when their text parses as an integer; JSON-looking values are parsed; anything else stays a string. The mapping is based on column names and value text rather than on PostgreSQL type OIDs — see mapRow.

See also
Database::executeQuery, mapRow

Entity builders keep constructing pqxx::params; this module turns that list into the bind calls Drogon needs, so no entity code changes for the async path. Parameter order is always the order in which the builder appended values, and parameters are transported as text unless pqxx reports a binary format.

See also
execSqlCoro, bindParams, toTextParams

Emits one bind operation per parameter: NULL, binary (format == 1) or text.

Binds a pqxx parameter list into an already-created Drogon SQL binder.

Binary values are copied into a shared, heap-owned buffer and passed as a RawParameter, so the bytes remain valid for the lifetime of the binder rather than for this stack frame. Text values are copied into a string.

Nulls are bound as SQL NULL; binary-format parameters are bound as a RawParameter whose bytes are held in a shared_ptr-owned buffer so they stay valid after this call; everything else is bound as a text string. Values are bound in append order.

Parameters
[in,out]binderBinder that already holds the statement text.
[in]paramsParameters to bind; not modified.
Precondition
The number and order of parameters match the placeholders in binder's statement; this function does not check.

bool asyncdb::isBusy ( const std::exception & error)

Tests whether an exception represents a busy database (pool exhaustion or timeout).

First checks for a DatabaseBusy by dynamic type; otherwise performs a case-sensitive substring search of what() for "timeout", "pool", "too many clients" and "connection". The message check is a heuristic used because callers catch exceptions as std::exception, where the specific Drogon type may not be available.

Parameters

Returns
True if the exception looks like a busy/timeout condition.
Warning

◆ mapRow()

jsoncons::json asyncdb::mapRow ( const drogon::orm::Result & result,
drogon::orm::Result::SizeType row )
nodiscard

Converts one row into a JSON object using name- and value-based type inference.

Maps one result row to a JSON object keyed by column name.

Each row gets its own object. Parse failures are swallowed and the raw text is kept, so this function never throws for a malformed integer or JSON value. Field values are read through their C-string text form.

Conversion order: SQL NULL to JSON null; a column named active to a boolean (t, true or 1 mean true); id, names ending in _id, appointment_duration and appointment_payment_amount to an integer when std::stoi succeeds; a non-empty value starting with { or [ to parsed JSON; otherwise a string. Both integer and JSON parsing failures fall back to the raw string, so a malformed value cannot abort mapping. A fresh object is built for each call, so no field can leak between rows.

Parameters
[in]resultResult set returned by the query.
[in]rowZero-based row index into result.
Returns
JSON object with one entry per column, in column order.
Precondition
row is a valid index into result.

Converts pqxx parameters into an ordered list of optional plain-text values.
