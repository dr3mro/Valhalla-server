Detailed Description

template<Client_t T>
class ClientController< T >

Client-specific handler that layers password hashing, sessions and account state over the generic CRUDS flow.

Inherits persistence from EntityController<T> and the full client contract from ClientControllerBase. Read/Search and their coroutine forms simply forward to EntityController; Create/Update dispatch their bodies to a PasswordWorker so password hashing never occupies a Drogon IO thread. Login/Logout are delegated to GateKeeper, and Suspend/Delete additionally invalidate sessions on success.

Template Parameters
TEntity type satisfying Client_t (derives from api::v2::Client), e.g. User or Provider.
Note
All overrides are final. Coroutine variants borrow their arguments and must be awaited while they live.
See also
ClientControllerBase, EntityController, PasswordWorker
