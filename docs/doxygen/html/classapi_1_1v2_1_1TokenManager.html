Detailed Description

Issues and validates the HS256 JWTs that authenticate clients.

Token parameters (issuer, type, validity and secret) come from the Configurator via KeeprBase. Generated tokens carry identity claims and last-logout time so a later logout can be detected. Validation first decodes the token into the ClientLoginData, then verifies it with KeeprBase::validateToken; the coroutine form awaits the async variant.

See also
KeeprBase In everyday words: this class is like a badge printer and badge checker. It stamps a badge with the user's identity and an expiry, and later checks that a presented badge is genuine and still current.
