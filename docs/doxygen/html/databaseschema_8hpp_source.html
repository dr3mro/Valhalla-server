1/**
2 * @file databaseschema.hpp
3 * @brief Process-wide cache of the database schema used by the validators.
4 * @details This header declares the DatabaseSchema class, which owns a single shared map
5 * describing every table and its columns. The map is filled once at server startup by asking
6 * DatabaseController for the table list and each table's columns, and is read-only afterwards.
7 * It also defines SCHEMA_t, the convenient name for that map's type, used throughout the
8 * validator code.
9 *
10 * WHY THIS FILE MATTERS IN THE SERVER:
11 * The validators need to know a table's columns and types to check client JSON, and querying
12 * the database on every request would be far too slow. This class provides that knowledge as
13 * a startup snapshot that Validator reads through getDatabaseSchema(). Without it, the
14 * validators would have no schema to compare against and would have to query the database on
15 * every create, update and read request.
16 *
17 * CONCEPTS TO LEARN (for beginners):
18 * - Static data members / storage duration: https://en.cppreference.com/w/cpp/language/storage_duration
19 *
20 * @author Amr Osman <dr3mro@gmail.com>
21 * @date 2026-11-16
22 */

34/**
35 * @class DatabaseSchema
36 * @brief Process-wide cache of the database schema used by the validators.
37 *
38 * @details The single static @ref databaseSchema map is populated at construction by querying
39 * DatabaseController for every table and its columns, and is thereafter read-only. The object
40 * is created eagerly by Server's constructor and owned by Store, so the schema is available
41 * before any request validation runs. Copy construction/assignment are allowed but share the
42 * same static state; move operations are explicitly disabled.
43 *
44 * @note Because the schema is a startup snapshot, schema changes made externally while the
45 * server is running are not reflected until restart.
46 * @warning Construction terminates the process (or throws) when no tables/columns can be
47 * read, so a reachable database is a startup prerequisite.
48 * @see Validator, DatabaseController, Store, SCHEMA_t
49 */
