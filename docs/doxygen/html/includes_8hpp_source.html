1/**
2 * @file includes.hpp
3 * @brief Umbrella header that makes every authorizable entity type complete for GateKeeper template instantiations.
4 * @details GateKeeper's permission-check helpers are templates, which means the compiler must
5 * see the full definition of each entity type before it can generate the right code.
6 * This header gathers all those entity definitions in one place. The IWYU pragmas on
7 * each line tell the "include-what-you-use" cleanup tool that these includes are
8 * intentional (they are needed by gatekeeper.cpp, even though this file does not
9 * mention the types itself). No functions or data live here; it is purely a list of
10 * headers so that call sites and the implementation file do not each repeat the
11 * whole entity graph.
12 *
13 * WHY THIS FILE MATTERS IN THE SERVER:
14 * This file supports the security layer. GateKeeper offers permission helpers like
15 * canRead<T>() and canDelete<T>() that work for many entity types (users, clinics, visits,
16 * appointments, and so on). In gatekeeper.cpp those helpers are explicitly instantiated once
17 * per supported type, which requires every type to be "complete" (fully defined) at that
18 * point. This header provides exactly that, so a new entity can be supported by adding one
19 * line here plus one instantiation in gatekeeper.cpp. Without it, gatekeeper.cpp would have
20 * to include twenty headers itself, and forgetting one would cause a confusing template
21 * compile error.
22 *
23 * CONCEPTS TO LEARN (for beginners):
24 * - Header / umbrella header: https://en.wikipedia.org/wiki/Include_guard
25 * - Template (compile-time generics): https://en.cppreference.com/w/cpp/language/templates
26 * - Explicit instantiation: https://en.cppreference.com/w/cpp/language/templates
27 * - Complete type (why the full definition is needed): https://en.cppreference.com/w/cpp/language/classes
28 * - Include-what-you-use tool: https://github.com/include-what-you-use/include-what-you-use
29 *
30 * @note No runtime code lives here; this file exists solely for template visibility.
31 * @author Amr Osman <dr3mro@gmail.com>
32 * @date 2026-11-16
33 */
