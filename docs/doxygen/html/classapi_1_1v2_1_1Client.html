Detailed Description

Entity for client-style tables (users, providers) with dedicated create/update builders.

Replaces Entity's generic JSON-based create/update builders with versions that consume the validated (column, value) pairs held by CreateClient_t/UpdateClient_t. Read, delete and search remain inherited from Entity. It also builds the active-flag toggle used to suspend/activate a client and can test whether a username is already taken. Concrete tables (User, Provider) derive from this class and supply the table name.

Note
All values in generated statements are bound through Binder; column names come from the validated data_set. The id used by updates/suspends is cached in client_id.
See also
Entity, Types::CreateClient_t, Types::UpdateClient_t
