Detailed Description

Implementation of the Validator checks declared in validator.hpp.

This file defines every function the header announces: the create, update and read validators, the per-field regular-expression validation, and the small private helpers that detect empty input, look up the cached schema, compare data types and walk through columns and keys. They all work on an in-memory schema snapshot and report problems by filling an api::v2::Http::Error with an HTTP status code and a message.

WHY THIS FILE MATTERS IN THE SERVER: This is where the validation rules actually run. Entity controllers call the public validateDatabase* functions before they build any SQL, and those functions lean on the private helpers here and on the cached schema owned by DatabaseSchema. Without this file the validators would be declarations only, and malformed client JSON would reach the database unchecked.

CONCEPTS TO LEARN (for beginners):

  • Regular expressions (regex): https://en.cppreference.com/w/cpp/regex
  • JSON schema validation: https://json-schema.org/
