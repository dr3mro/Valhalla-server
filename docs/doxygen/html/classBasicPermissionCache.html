Detailed Description

template<typename ClockT = std::chrono:: steady_clock>
class BasicPermissionCache< ClockT >

Idle-expiry cache for permission lookups, keyed by the generated permission query (which embeds the entity table and id).

Each hit renews the entry's lifetime; an entry that is not used for the TTL is removed. The TTL comes from Configurator::PermissionCacheConfig (PERMISSION_CACHE_TTL, default 300 seconds); 0 disables the cache.

Security trade-off: there is no invalidation on writes, so a revoked permission can keep being served while its entry stays in use. invalidateAll() is available for callers that need an explicit flush. 

     All public operations are thread-safe via mutex_; generation_ is

atomic so readers can take a token without locking and have a racing put() rejected. Think of it as a notepad: look up a question, and if the answer is still fresh use it; otherwise ask the database and jot the new answer down.
