2 * @file clinics.hpp
3 * @brief Service entity bound to the `clinics` table; the organisation root for clinic cases.
4 * @details This header declares the Clinics class, a very small C++ type that stands for one clinic in the `clinics`
5 * database table. Like the other service providers, it holds almost no logic of its own: it only names the
6 * table and lets its parent class Service build the SQL. You create one by passing in a data wrapper made from
7 * a client request, and the parent stores that wrapper. This table is also special: it is the organisation
8 * that every clinic case (patient, visit, report, ...) ultimately belongs to.
9 *
10 * WHY THIS FILE MATTERS IN THE SERVER:
11 * Clinics is both a service provider (clinics can be created, read, updated and deleted through the service/clinic
12 * routes) and the organisation root used by the permission system. Case::ORGNAME is "clinics", and every Case
13 * permission query joins this table to recover the owning clinic's owner, admin and staff columns. The route layer
14 * selects ServiceController<Clinics> / StaffController<Clinics> for clinic endpoints. Without this file there would be
15 * no C++ type tying the `clinics` table to the CRUD machinery, and the permission system could not tell which clinic
16 * owns a given case.
17 *
18 * CONCEPTS TO LEARN (for beginners):
19 * - static constexpr: a value fixed at compile time that belongs to the class, not to one object. https://en.cppreference.com/w/cpp/language/static
20 * - JSON: a text format used to carry request data; this project uses the jsoncons library to read it. https://jsoncons.github.io/jsoncons/
21 * - Template (`template <typename T>`): a blueprint that works with whatever data type the caller supplies. https://en.cppreference.com/w/cpp
22 *
23 * @author Amr Osman <dr3mro@gmail.com>
24 * @date 2026-11-16
25 */
