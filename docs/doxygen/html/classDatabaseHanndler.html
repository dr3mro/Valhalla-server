Detailed Description

RAII lease of a single pooled Database connection.

The constructor leases a connection from a DatabaseConnectionPool (waiting up to the acquire timeout and possibly throwing DatabaseBusy); the destructor returns it, so a thrown query exception cannot leak the connection. Intended as a short-lived, stack-allocated helper (the watchdog and controllers create one per check/query). Non-copyable and non-movable: one lease, one connection.

Note
The class name is spelled DatabaseHanndler as used throughout the codebase.
