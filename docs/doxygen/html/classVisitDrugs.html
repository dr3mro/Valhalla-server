Detailed Description

Case entity for the patients_visitdrugs table (drugs recorded for a visit).

A thin value type that binds the generic Case/Entity CRUD machinery to one table. Despite the patients_ prefix of the table name, create-authorisation is resolved through a visit: CREATE_KEY identifies a clinics_visits row, whose clinic_id links to the owning clinic. SQL generation is inherited; this class only fixes the table name and the reference table. The static getPermissionsQueryFor* helpers are taken as function pointers by PermissionManager::canCreate/canRead/canUpdate/canDelete for api::v2::Case_t T. Registered as ClinicController<VisitDrugs> under the visitDrugs serviceType. Ownership: the data wrapper is copied into Entity and is const thereafter; no mutable state and no locking of its own. Copy and move are deleted by Case.

Note
No default constructor: Entity needs a data wrapper to build statements from.

Case, Entity, PermissionManager, ClinicController

std::optional< std::string > VisitDrugs::getPermissionsQueryForCreate ( const std::optional< jsoncons::json > & data_j)
inlinestatic

Builds the SQL that resolves the owning clinic for a create request.

Reads the visit id from data_j using CREATE_KEY and delegates to the Case base, which joins clinics with clinics_visits on clinic_id. PermissionManager runs the returned SELECT before the insert; no insert occurs here.

Parameters
[in]data_jCreate payload; must be engaged and contain an unsigned-integer CREATE_KEY (the optional is dereferenced without a has_value() check).
Returns
The SELECT statement, or std::nullopt if reading or converting the key throws; the exception is logged via CRITICALMESSAGE.
