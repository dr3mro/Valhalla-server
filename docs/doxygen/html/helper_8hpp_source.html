1/**
2 * @file helper.hpp
3 * @brief Factory for the standard JSON HTTP responses used by the v2
4 * controllers and filters.
5 * @details This header declares the Helper utility class. Its static functions
6 * build the three kinds of reply the API sends: a 500 "Failure", an
7 * arbitrary-status "Error", and a 200 "Success" whose body is already JSON. A
8 * private reply function does the actual work of setting the status, content
9 * type and body, and adds a Retry-After header to 503 replies. The prepare
10 * function wraps a message in a JSON object with a "Status" field.
11 *
12 * WHY THIS FILE MATTERS IN THE SERVER:
13 * Helper gives the entire API one consistent response format. Controllers and
14 * filters call these functions instead of hand-building HTTP responses, so
15 * clients always receive the same JSON shape for errors and the same headers
16 * for retryable failures. It is used by common.hpp, the Auth filter and every
17 * route controller. Without it each handler would invent its own error format
18 * and clients could not reliably understand failures.
19 *
20 * CONCEPTS TO LEARN (for beginners):
21 * - Static utility class: a class used as a namespace for functions, never
22 * instantiated.
23 * - HTTP status codes: https://developer.mozilla.org/en-US/docs/Web/HTTP/Status
24 * - std::function callback:
25 * https://en.cppreference.com/w/cpp/utility/functional/function
26 * - JSON:
27 * https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/JSON
28 *
29 * @author Amr Osman <dr3mro@gmail.com>
30 * @date 2026-11-16
31 */

49 /**
50 * @class Helper
51 * @brief Factory for the standard JSON HTTP responses used by the v2
52 * controllers and filters.
53 * @details All members are static; the class is a namespace-like utility
54 * with no state. The response callbacks are consumed (moved from) exactly
55 * once to deliver the reply. failure/error responses wrap the message in a
56 * JSON object with a "Status" field, while success responses pass the
57 * message through as-is. Every reply is JSON with a 503 response
58 * additionally carrying Retry-After: 1.
59 * @note Copyable but non-movable; construction is unrestricted but
60 * meaningless since there is no instance state.
