Detailed Description

Umbrella header that makes every authorizable entity type complete for GateKeeper template instantiations.

GateKeeper's permission-check helpers are templates, which means the compiler must see the full definition of each entity type before it can generate the right code. This header gathers all those entity definitions in one place. The IWYU pragmas on each line tell the "include-what-you-use" cleanup tool that these includes are intentional (they are needed by gatekeeper.cpp, even though this file does not mention the types itself). No functions or data live here; it is purely a list of headers so that call sites and the implementation file do not each repeat the whole entity graph.

WHY THIS FILE MATTERS IN THE SERVER: This file supports the security layer. GateKeeper offers permission helpers like canRead<T>() and canDelete<T>() that work for many entity types (users, clinics, visits, appointments, and so on). In gatekeeper.cpp those helpers are explicitly instantiated once per supported type, which requires every type to be "complete" (fully defined) at that point. This header provides exactly that, so a new entity can be supported by adding one line here plus one instantiation in gatekeeper.cpp. Without it, gatekeeper.cpp would have to include twenty headers itself, and forgetting one would cause a confusing template compile error.
