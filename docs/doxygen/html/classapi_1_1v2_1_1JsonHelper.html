Detailed Description

Stateless bridge between the two JSON libraries and response bodies.

The codebase uses JsonCpp for HTTP responses (Drogon) and jsoncons for validation. This utility wraps simple message objects and serialises either representation to a pretty-printed string. All members are static and construction is deleted: there is no state and no thread-safety concern beyond the underlying libraries.
