1/**
2 * @file dbexecutor.cpp
3 * @brief Implementation for dbexecutor: Builds the executor from configuration, naming it "DB executor" for diagnostics.
4 * @details This file implements the two DbExecutor constructors. Both forward the worker,
5 * queue and name settings to the BoundedExecutor base and store the IO fast-path
6 * flag. The default constructor reads every setting from the application-wide
7 * Configurator; the other takes explicit values, which keeps unit tests independent
8 * of configuration.
9 *
10 * WHY THIS FILE MATTERS IN THE SERVER:
11 * It is the small piece that turns configured numbers into the actual worker pool used for all
12 * blocking database work. The "DB executor" label passed to the base class shows up in logs
13 * and statistics, so operators can tune worker counts and queue sizes. Without these
14 * constructors the DbExecutor declared in the header could not be created, and routes would
15 * have nowhere to send blocking queries.
16 *
17 * CONCEPTS TO LEARN (for beginners):
18 * - Base-class initialisation in a constructor initializer list: https://en.cppreference.com/w/cpp/language/initializer_list
19 * - Anonymous namespaces (keep helpers private to one .cpp file): https://en.cppreference.com/w/cpp/language/namespace
20 * - Configuration via a service locator / Store pattern
21 * - std::size_t: https://en.cppreference.com/w/cpp/types/size_t
22 *
23 * @author Amr Osman <dr3mro@gmail.com>
24 * @date 2026-11-16
25 */
