Detailed Description

Case entity for the clinics_prescriptions table (a visit's prescriptions).

This header declares the Prescriptions class, a small C++ type that stands for the prescriptions record of one visit in the clinics_prescriptions database table. There is at most one such record per visit because the visit id is the table's primary key. The class itself holds no data; it names the table and leaves SQL generation to its parent Case. It also supplies small helper functions that build permission-checking SQL for create, read, update and delete operations.

WHY THIS FILE MATTERS IN THE SERVER: Prescriptions is one of the clinic-owned "case" types exposed through the clinic routes as ClinicController<Prescriptions> under the prescriptions service type. When a client wants to add or change a visit's prescriptions, PermissionManager calls the static getPermissionsQueryFor* helpers here to build a SELECT that finds which clinic owns the visit (via clinics_visits), then checks whether the requesting user is that clinic's owner, admin or staff. Without this file there would be no C++ type connecting the clinics_prescriptions table to the CRUD and permission machinery, so prescriptions endpoints could not work.

CONCEPTS TO LEARN (for beginners):

  • static constexpr: a value fixed at compile time that belongs to the class, not to one object. https://en.cppreference.com/w/cpp/language/static
  • JSON: a text format used to carry request data; this project uses the jsoncons library to read it. https://jsoncons.github.io/jsoncons/
  • Foreign key / ON DELETE CASCADE: a column that points to a row in another table, with the database automatically deleting this row when that parent row is deleted. https://en.cppreference.com/w/cpp
