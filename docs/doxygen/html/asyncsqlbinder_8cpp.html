Detailed Description

Implementation for asyncsqlbinder: Copies each parameter's bytes into a string, or records a null when pqxx reports no value.

This file implements the three bridge functions declared in asyncsqlbinder.hpp. toTextParams() copies parameters into optional strings, bindParams() feeds them into a Drogon SQL binder one at a time, and execSqlCoro() creates that binder and returns an awaiter. All three work from the C-style parameter view that pqxx exposes, which reports each value's bytes, length and format.

WHY THIS FILE MATTERS IN THE SERVER: This is the actual data-copy layer of every asynchronous database query. The entity builders still hand over pqxx::params, and this file is where those values are transformed into Drogon bind calls. Copying by the reported length keeps embedded NUL bytes intact, and putting binary data in a shared buffer keeps it alive until the query finishes rather than only until this function returns. Without these details, async queries would corrupt binary values, mishandle nulls, or read memory that has already gone away.
