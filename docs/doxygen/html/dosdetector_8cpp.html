Detailed Description

Implementation for dosdetector: Production constructor: compiles configured matchers and starts the cleanup thread.

This file contains the working logic of the per-IP abuse detector. The constructors turn configuration strings (regular expressions, CIDR ranges, wildcards, exact IPs) into small predicate functions and launch a background cleanup thread. is_dos_attack() is the main entry point: it checks the static lists first, then the dynamic rate/ban state, and records each request so repeat offenders can be escalated. A separate helper hashes the request into a fingerprint, and several mutex-guarded maps hold the timestamps and block/unblock times.

WHY THIS FILE MATTERS IN THE SERVER: This file is the actual "bouncer" behind Filters::RateLimit. Every request that reaches the rate-limit filter ends up in is_dos_attack(), which returns a Status the filter turns into an allow or an HTTP error. It calls into Configurator (read at construction), xxHash (to fingerprint requests) and Message (for logging). Without this implementation the detector class in the header would have no behaviour, and the server would be unable to detect or slow down flooding and brute-force clients.
