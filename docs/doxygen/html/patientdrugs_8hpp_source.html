1/**
2 * @file patientdrugs.hpp
3 * @brief Case entity for the `patients_drugs` table (a patient's drug record).
4 * @details This header declares the PatientDrugs class, a small C++ type that stands for the drug record of one patient
5 * in the `patients_drugs` database table. There is at most one such record per patient because the patient id
6 * is the table's primary key. The class itself holds no data; it names the table and leaves SQL generation to
7 * its parent Case. It also supplies small helper functions that build permission-checking SQL for create,
8 * read, update and delete operations.
9 *
10 * WHY THIS FILE MATTERS IN THE SERVER:
11 * PatientDrugs is one of the clinic-owned "case" types exposed through the clinic routes as
12 * ClinicController<PatientDrugs> under the `patientdrugs` service type. When a client wants to add or change a patient's
13 * drug record, PermissionManager calls the static getPermissionsQueryFor* helpers here to build a SELECT that finds
14 * which clinic owns the patient, then checks whether the requesting user is that clinic's owner, admin or staff. Without
15 * this file there would be no C++ type connecting the `patients_drugs` table to the CRUD and permission machinery, so
16 * patient-drug endpoints could not work.
17 *
18 * CONCEPTS TO LEARN (for beginners):
19 * - static constexpr: a value fixed at compile time that belongs to the class, not to one object. https://en.cppreference.com/w/cpp/language/static
20 * - JSON: a text format used to carry request data; this project uses the jsoncons library to read it. https://jsoncons.github.io/jsoncons/
21 * - Foreign key / ON DELETE CASCADE: a column that points to a row in another table, with the database automatically
22 * deleting this row when that parent row is deleted. https://en.cppreference.com/w/cpp
23 *
24 * @author Amr Osman <dr3mro@gmail.com>
25 * @date 2026-11-16
26 */
