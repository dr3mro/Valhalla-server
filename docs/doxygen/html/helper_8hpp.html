Detailed Description

Factory for the standard JSON HTTP responses used by the v2 controllers and filters.

This header declares the Helper utility class. Its static functions build the three kinds of reply the API sends: a 500 "Failure", an arbitrary-status "Error", and a 200 "Success" whose body is already JSON. A private reply function does the actual work of setting the status, content type and body, and adds a Retry-After header to 503 replies. The prepare function wraps a message in a JSON object with a "Status" field.

WHY THIS FILE MATTERS IN THE SERVER: Helper gives the entire API one consistent response format. Controllers and filters call these functions instead of hand-building HTTP responses, so clients always receive the same JSON shape for errors and the same headers for retryable failures. It is used by common.hpp, the Auth filter and every route controller. Without it each handler would invent its own error format and clients could not reliably understand failures.

CONCEPTS TO LEARN (for beginners):

  • Static utility class: a class used as a namespace for functions, never instantiated.
  • HTTP status codes: https://developer.mozilla.org/en-US/docs/Web/HTTP/Status
  • std::function callback: https://en.cppreference.com/w/cpp/utility/functional/function
