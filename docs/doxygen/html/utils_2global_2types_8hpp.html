Detailed Description

Shared value types and their hash specialisations.

Defines the ColumnInfo struct, which describes one database column, and teaches std::hash how to hash it (and a pair of strings). Hashing matters because these types are used as keys in unordered containers such as unordered_set. Equality and hashing deliberately look at the same three fields so that two "equal" objects always get the same hash.

WHY THIS FILE MATTERS IN THE SERVER: The schema validator compares database table descriptions. It stores columns in hash-based sets, which need both an operator== and a std::hash to work. This file provides both, and deliberately ignores the "Constraint" text so a column is recognised by its name, data type and nullability alone. Without these definitions the unordered sets would not compile for ColumnInfo.
