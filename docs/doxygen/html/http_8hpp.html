Detailed Description

HTTP status codes and error payloads shared by the API layer.

Defines the Error struct (a numeric code plus a message) and the Status enum, which lists the HTTP response codes this server uses. The enum is grouped into the standard families: 1xx informational, 2xx success, 3xx redirection, 4xx client error and 5xx server error. A small helper, getDescription, turns a Status value into its standard human-readable reason phrase (for example "OK" or "Not Found").

WHY THIS FILE MATTERS IN THE SERVER: Every callback in the API reports its outcome as an integer status code, and this file is the single vocabulary of those codes. Controllers, the error macros and the response builders all use Status values so a "404" means the same thing everywhere. getDescription lets the server include a readable reason phrase when needed. Without this shared list, status codes would be magic numbers scattered through the code with no consistent meaning.
