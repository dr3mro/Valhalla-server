1/**
2 * @file asyncdbclient.hpp
3 * @brief Store-registered holder for the Drogon PostgreSQL client used when DB_ASYNC=true.
4 * @details This header defines one small class that owns a Drogon database client. The client is kept in a shared
5 * pointer so several parts of the server can refer to the same underlying connection pool. The class also
6 * contains two helpers: one that builds the client from the database settings, and one that writes those
7 * settings into the keyword/value string PostgreSQL expects.
8 *
9 * WHY THIS FILE MATTERS IN THE SERVER:
10 * This file is the home of the asynchronous (non-blocking) database client. When the DB_ASYNC setting is on, the
11 * server startup code (Server::run()) calls AsyncDbClient::createClient() and stores the result in the Store, which
12 * is the server's shared service registry. Later, each database controller method fetches this object from the Store
13 * and passes the Drogon client inside it to asyncdb::execSqlCoro(), which runs the SQL without occupying a worker
14 * thread. Tests can register a fake (or empty) client through Store::replaceObject(). Without this file there would
15 * be no way for the async controllers to reach PostgreSQL, and the whole DB_ASYNC code path would be unreachable;
16 * the older synchronous connection pool would remain the only working option.
17 *
18 * CONCEPTS TO LEARN (for beginners):
19 * - C++20 coroutines: https://en.cppreference.com/w/cpp/language/coroutines
20 * - Drogon DbClient: https://drogon.docsforge.com/master/database/
21 * - std::shared_ptr (shared ownership of one object): https://en.cppreference.com/w/cpp/memory/shared_ptr
22 * - RAII (tying a resource's lifetime to an object's lifetime): https://en.cppreference.com/w/cpp/language/raii
23 * - PostgreSQL connection strings: https://www.postgresql.org/docs/current/libpq-connect.html#LIBPQ-CONNSTRING
24 *
25 * @author Amr Osman <dr3mro@gmail.com>
26 * @date 2026-11-16
27 */

38/**
39 * @class AsyncDbClient
40 * @brief Store-registered holder for the Drogon PostgreSQL client used when DB_ASYNC=true.
41 * @details The wrapper holds a `shared_ptr<drogon::orm::DbClient>`; production instances are created from the DB_* settings.
42 * `Server::run()` registers it in the Store only while `DatabaseConfig::async` is enabled; the synchronous pool
43 * stays in use while the flag is off. Callers fetch it with `Store::getObject<AsyncDbClient>(nullptr)` and hand
44 * the underlying client to `asyncdb::execSqlCoro`. Tests replace the registered instance through
45 * `Store::replaceObject`; a null client is a valid state meaning "async path unavailable", which the controller
46 * treats as `std::nullopt`.
47 * The wrapper itself is non-copyable and non-movable so there is a single long-lived Store-owned instance. It adds
48 * no locking of its own; any thread-safety comes from the underlying Drogon DbClient.
49 * @see createClient, asyncdb::execSqlCoro, DatabaseController::executeQueryCoro
50 */
51class AsyncDbClient
52{
53 public:
54 /**
55 * @brief Constructs the wrapper around an already-created Drogon client.
56 * @param[in] client Client to share ownership of; may be null (used by tests and the unavailable state).
57 * @post `client()` returns the same pointer that was passed in.
58 */
59 explicit AsyncDbClient(std::shared_ptr<drogon::orm::DbClient> client); // `explicit` prevents accidental implicit conversion from a bare pointer.
60
61 /**
62 * @brief Copy and move operations are disabled.
63 * @details The wrapper is a single Store-owned object; tests swap the whole `shared_ptr` via `Store::replaceObject`
64 * rather than copying or moving the wrapper.
65 */
66 AsyncDbClient(const AsyncDbClient&) = delete; // No second wrapper may be made by copying: that would blur "one registered client".
67 AsyncDbClient(AsyncDbClient&&) = delete; // No move construction either: the Store owns the object at a fixed address.
68 AsyncDbClient& operator=(const AsyncDbClient&) = delete; // No copy assignment: replacing the client is done through the Store, not here.
69 AsyncDbClient& operator=(AsyncDbClient&&) = delete; // No move assignment: keeps the wrapper's identity stable for its whole lifetime.
70
71 /** @brief Defaulted virtual destructor; connection cleanup is delegated to the owned Drogon client.
72 * @note Virtual per the project-wide convention (commit 217a477); no class derives from this type.
73 */
74 virtual ~AsyncDbClient() = default; // The shared_ptr member frees the client (and its pool) when the last owner disappears.
75
76 /**
77 * @brief Builds a Drogon PostgreSQL client from the configuration held in the Store.
78 * @details Reads `Configurator::DatabaseConfig` from the Store, builds the connection string with `connectionString`,
79 * requests `DB_MAX_CONN` connections and applies the acquire timeout, converting milliseconds to the seconds
80 * Drogon expects.
81 * @return A newly created client, ready to be wrapped and registered with `Store::registerObject<AsyncDbClient>`.
82 * @pre A `Configurator` object is registered in the Store.
83 */
84 static std::shared_ptr<drogon::orm::DbClient> createClient(); // Factory: `static` means you call it on the class, without an existing object.
85
86 /**
87 * @brief Renders a libpq keyword/value connection string from a database configuration.
88 * @param[in] config Source of host, port, database name, user, password and SSL settings.
89 * @return `host=... port=... dbname=... user=... password=... connect_timeout=2 sslmode=require|disable`.
90 * @warning The returned string contains the database password in clear text; it must not be logged. `printValues()`
91 * on the configuration deliberately redacts the same field.
92 */
93 static std::string connectionString(const Configurator::DatabaseConfig& config); // Pure formatting: no connection is opened, only text is produced.
94
95 /**
96 * @brief Returns the owned client, which may be null.
97 * @return Const reference to the stored `shared_ptr`; it remains valid for the lifetime of this wrapper.
98 */
99 [[nodiscard]] const std::shared_ptr<drogon::orm::DbClient>& client() const { return client_; } // `[[nodiscard]]` warns if a caller ignores the answer; the reference avoids copying the pointer.
100
101 private:
102 /**
103 * Shared ownership of the Drogon client; null in test fakes and the disabled state.
104 */
105 std::shared_ptr<drogon::orm::DbClient> client_; // The single piece of state this class exists to hold; `shared_ptr` keeps the pool alive as long as anyone uses it.
106};
