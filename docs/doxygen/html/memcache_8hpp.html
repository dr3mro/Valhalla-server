Detailed Description

Thread-safe in-memory LRU cache with TTL expiry and a cleaner thread.

Defines a template MemCache<T, ClockT> that stores values by key in memory. A hash map maps keys to positions in a list, giving constant- time lookup and cheap reordering: the list is kept in "most recently used first" order so the least recently used item can be evicted when capacity is reached. Each entry has a time-to-live (TTL); a background thread periodically removes expired entries, and get() treats expired entries as misses. A single mutex protects all state, so the cache is safe to share between threads. Move and destruction stop the cleaner thread before any state is touched.

WHY THIS FILE MATTERS IN THE SERVER: Some data is expensive to fetch (for example permissions or database results) but does not change often. This cache lets the server keep a bounded, temporary copy in memory so repeated requests are fast. The TTL ensures stale data does not live forever, and the LRU limit stops it from growing without bound. It is a self-contained header-only utility, used wherever a caller wants a safe, time-limited store; without it every caller would build its own cache and duplicate the expiry and thread-safety logic.
