1/**
2 * @file dbexecutor.hpp
3 * @brief BoundedExecutor configured for the synchronous database path.
4 * @details This header declares DbExecutor, a thin subclass of BoundedExecutor
5 * that runs blocking database work off the Drogon IO threads. It has two
6 * constructors: one takes worker count, queue size and fast-path flag from
7 * configuration, the other takes explicit sizes for tests. It also provides
8 * runOnDbExecutor(), a helper that submits work and answers 503 itself if the
9 * bounded queue is full.
10 *
11 * WHY THIS FILE MATTERS IN THE SERVER:
12 * Drogon's IO threads must stay free to accept and route HTTP requests; a slow
13 * SQL query on one of them would stall every other request. Routes obtain the
14 * shared DbExecutor from the Store and call runOnDbExecutor() so permission
15 * checks, queries and response building run on dedicated workers. The optional
16 * IO-thread fast path (see dbprobe.hpp) lets requests that need no database
17 * finish without ever queueing. Without this executor, blocking database work
18 * would run on IO threads and the server would grind to a halt under load.
19 *
20 * CONCEPTS TO LEARN (for beginners):
21 * - Inheritance / derived classes:
22 * https://en.cppreference.com/w/cpp/language/derived_class
23 * - Function templates:
24 * https://en.cppreference.com/w/cpp/language/function_template
25 * - Perfect forwarding (std::forward):
26 * https://en.cppreference.com/w/cpp/utility/forward
27 * - std::size_t (an unsigned size type):
28 * https://en.cppreference.com/w/cpp/types/size_t
29 * - Thread pools and bounded queues (back-pressure)
30 *
31 * @author Amr Osman <dr3mro@gmail.com>
32 * @date 2026-11-16
33 */

109/**
110 * @brief Submits `body` to a DbExecutor, answering 503 if it cannot be
111 * accepted.
112 * @details Wraps runOnExecutor with the database-busy message. The callback is
113 * shared with the queued task so it remains available for the 503 reply if
114 * submission fails. Any database work that must not run on an IO thread belongs
115 * in `body`.
116 * @tparam Body Callable taking a `CALLBACK_` by value/rvalue reference.
117 * @param[in,out] executor Executor that runs the body.
118 * @param[in,out] callback Completion callback invoked with (status, message).
119 * @param[in,out] body Work to run on a worker; not invoked when the queue is
120 * full.
121 * @post Exactly one of `body` (on a worker) or `callback` with 503 (on the
122 * caller) runs.
123 */
124template <typename Body>
125void runOnDbExecutor(DbExecutor& executor, CALLBACK_&& callback, Body&& body) {
126 runOnExecutor(executor,
127 std::move(callback),
128 "The server is busy, try again shortly.",
129 std::forward<Body>(
130 body)); // Reuse the generic helper; the busy message here
131 // tells clients to retry when the DB queue is
132 // full.
133}
