Detailed Description

Convenience alias for the staff-invitation payload consumed by Service builders.

This header defines the Service entity for organisation tables such as clinics, pharmacies, laboratories and radiology centres. On top of the inherited CRUD statements it adds two builders that edit the JSONB "staff" array of a service row to add or remove a team member, and a static query that PermissionManager uses to read a service's owner, admin and staff.

WHY THIS FILE MATTERS IN THE SERVER: Services (organisations) need to manage teams, and permission checks need to know who owns or administers a service. Controllers use Service to build the jsonb_set UPDATEs that change the staff array and the SELECT that feeds PermissionManager. Without it there would be no safe way to add/remove staff or to authorise service-level operations.

CONCEPTS TO LEARN (for beginners):

  • std::optional: https://en.cppreference.com/w/cpp/utility/optional
  • JSONB: PostgreSQL's binary JSON column type; jsonb_set changes a value at a path inside it and the -> operator walks into a JSON object.
  • SQL parameter binding: put $1, $2, ... markers in the SQL and pass the real values separately; see https://en.cppreference.com/w/cpp or the libpqxx documentation.
  • Type alias (using StaffData = ...): a short local name for a longer qualified type; no new type is created.
