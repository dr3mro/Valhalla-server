Detailed Description

Appointment-entity controller that adapts EntityController to AppointmentControllerBase.

In plain words, this file defines a small "adapter" class for each kind of appointment (clinic appointment, pharmacy appointment, laboratory appointment, radiology-center appointment). An adapter is a thin wrapper that passes a request straight through to another class that does the real work — here EntityController. Every job below (create, read, update, delete, search and their coroutine versions) simply forwards to the matching method of EntityController<T>. This class adds no behaviour of its own: validation, permission checks, building the database query, turning results into JSON and mapping errors to HTTP codes all happen in that base class.

WHY THIS FILE MATTERS IN THE SERVER: It gives appointment entities their own interface, separate from service entities, so the route registry can pick the right controller family by name. The HTTP layer calls these methods through AppointmentControllerBase (using a std::variant), and each call lands here and is handed to EntityController. If this file were missing, there would be no concrete class satisfying the appointment interface and no way to route an appointment request to the real CRUD+S code.
