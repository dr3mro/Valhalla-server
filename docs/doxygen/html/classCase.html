Detailed Description

Base entity for clinic-owned clinical records (patients, visits, reports, ...).

Extends Entity with a fixed organisation name ("clinics") and a family of static permission-query builders. Concrete service entities derive from Case and expose those builders to PermissionManager, which executes the returned query to decide whether a requester may create/read/update/delete a record. The builders select the owner, admin and staff columns of the owning clinic (joined to the record table where needed).

Note
Unlike the CRUD builders in Entity, these queries interpolate the id and table names into the SQL text via fmt::format and take no pqxx::params; they are called with internal, trusted values and the resulting text is also used as a cache key by PermissionManager.
See also
Entity, PermissionManager
