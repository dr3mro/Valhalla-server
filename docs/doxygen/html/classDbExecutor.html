Detailed Description

BoundedExecutor configured for the synchronous database path.

Runs blocking database work (permission checks, queries, response building) off the Drogon IO threads. Worker count and queue capacity come from configuration in the default constructor; the other constructor allows explicit sizes for tests. When configured, requests may first be attempted on the IO thread via a DbProbe (see ioFastPath()). Thread-safety and shutdown semantics are inherited from BoundedExecutor.

See also
BoundedExecutor, DbProbe, runOnDbExecutor
