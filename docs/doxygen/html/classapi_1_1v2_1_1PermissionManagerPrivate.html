Detailed Description

Implementation helpers shared by the PermissionManager authorization overloads.

Pure static utilities: they interpret the permission JSON returned by the database (owner/admin ids, staff capability strings), enforce group/id checks and create preconditions, and fetch/cache entity permissions through PermissionCache. Sync helpers use DatabaseController::getPermissions; the *Coro variant awaits getPermissionsCoro. All denial/error details are written to the caller-provided Http::Error.

Note
The class holds no state; all members are static. In everyday words: this is a toolbox, not a machine. You never make one; you call its named tools with the facts and get a yes/no back.

Fetches an entity's permission JSON, serving the idle-expiry cache when possible.

func is invoked with args to generate the cache key/query (which embeds the entity table and id). On a cache hit no database access occurs. On a miss the generation token is captured before the read so a concurrent invalidateAll() makes the subsequent put() a no-op. Empty results are not cached.
