2 * @file databasebusy.hpp
3 * @brief Exception signalling that the connection pool could not lease a connection in time.
4 * @details This header defines DatabaseBusy, a tiny exception class used as a signal. It adds
5 * no data of its own; it simply derives from std::runtime_error with a default message
6 * so it can be caught either specifically or by generic error handlers. Its whole
7 * purpose is to give "the pool is exhausted" a distinct type.
8 *
9 * WHY THIS FILE MATTERS IN THE SERVER:
10 * The HTTP layer needs to tell two very different failures apart: a broken query (probably a
11 * server bug, answer 500) and a temporary shortage of connections (the client should retry,
12 * answer 503 with Retry-After). DatabaseConnectionPool::get_connection() throws this type when
13 * its wait expires, and filters, controllers and the watchdog all catch it separately. Without
14 * a dedicated type, every timeout would look like a generic error and clients would not know
15 * to retry.
16 *
17 * CONCEPTS TO LEARN (for beginners):
18 * - Exceptions and catch blocks: https://en.cppreference.com/w/cpp/language/try_catch
19 * - std::runtime_error (a standard exception carrying a message): https://en.cppreference.com/w/cpp/error/runtime_error
20 * - Inheritance: https://en.cppreference.com/w/cpp/language/derived_class
21 * - HTTP 503 Service Unavailable and Retry-After
22 * - explicit constructors (prevent accidental implicit conversion): https://en.cppreference.com/w/cpp/language/explicit
23 *
24 * @author Amr Osman <dr3mro@gmail.com>
25 * @date 2026-11-16
26 */
