Detailed Description

Defines the Store's single shared registry, lock and generation counter.

This file contains no functions. It only gives real storage to the three static variables that store.hpp declares: a map from a C++ type to its one shared object, a mutex protecting that map, and a counter used to refresh per-thread caches. The counter starts at 1 so that a brand-new thread, whose remembered value starts at 0, always performs a lookup the first time it asks for an object.

WHY THIS FILE MATTERS IN THE SERVER: These few definitions are the physical storage behind the service locator. Every call to Store::getObject(), Store::cachedObject() or Store::replaceObject() reads or changes these variables. Without this file the header would only declare names and the linker would report "undefined reference" errors. Tests also depend on the counter starting at 1, so a freshly installed fake is noticed on the very first cached lookup.

CONCEPTS TO LEARN (for beginners):

  • None difficult here; this file only provides real storage (a "definition") for names declared in the header.
