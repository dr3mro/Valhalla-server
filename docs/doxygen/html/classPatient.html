Detailed Description

Case entity for the patients table; the patient record owned by a clinic.

A thin value type binding the generic Case/Entity CRUD machinery to one table. SQL generation is inherited; this class fixes the table name and overrides create authorisation: because a patient belongs directly to a clinic, the create payload's clinic_id is checked against clinics without the patient-table join used by the other Case types. This is also the only Case that builds a visits query; the controller uses it in GetVisits/GetVisitsAsync (guarded by requires std::is_same<T, Patient>). The static getPermissionsQueryFor* helpers are passed to PermissionManager for api::v2::Case_t T. The type is registered as ClinicController<Patient> under the patients serviceType, which also owns search and getvisits routes. Ownership: the wrapper is copied into Entity and is const thereafter; no mutable state and no locking of its own. Copy and move are explicitly deleted: create a fresh instance per operation.

Note
No default constructor: Entity needs a data wrapper to build statements from.

std::optional< std::string > Patient::getPermissionsQueryForCreate ( const std::optional< jsoncons::json > & data_j)
inlinestatic

Builds the SQL that resolves the owning clinic for a create request.

Reads clinic_id from data_j and calls the Case base's patient-specific helper, which selects owner/admin/staff directly from clinics where id equals that value. PermissionManager runs the returned SELECT before the insert; no insert occurs here.

Parameters
[in]data_jCreate payload; must be engaged and contain an unsigned-integer clinic_id (the optional is dereferenced without a has_value() check).
Returns
The SELECT statement, or std::nullopt if reading or converting the key throws; the exception is logged via CRITICALMESSAGE.

◆ getSqlGetVisitsStatement()

std::optional< std::string > Patient::getSqlGetVisitsStatement ( pqxx::params & params)
inline

Builds the SELECT that lists all visits of this patient.

Resets params, binds the patient id held in the Data_t wrapper, and returns the query over clinics_visits. Controller::GetVisits / GetVisitsAsync execute it with those same params and serialise the rows back to the caller.

Parameters
[in,out]paramsBound parameters, cleared before the patient id is appended.
Returns
The SELECT * FROM clinics_visits WHERE patient_id = $1; statement.
Precondition
The entity must hold a Data_t with an id.
Exceptions
std::bad_variant_accessif the stored wrapper is not a Data_t.
std::bad_optional_accessif that wrapper has no id.
Note
These exceptions are not caught here; the controller's handler catches them.
