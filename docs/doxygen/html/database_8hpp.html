Detailed Description

Owns one synchronous PostgreSQL connection used by the synchronous database path.

This header declares the Database class, a thin wrapper around one libpqxx connection to a PostgreSQL server. It offers small helpers to check whether a row exists, probe whether the link is still alive, reconnect after a failure, run parameterised SQL and turn the returned rows into JSON, and read table metadata.

WHY THIS FILE MATTERS IN THE SERVER: This is the lowest-level building block of the synchronous ("blocking") database path. DatabaseConnectionPool creates these objects and leases them out one borrower at a time; DatabaseHanndler holds a lease for the length of one request; controllers call the query helpers declared here to read and write application data. Without this class the server would have no way to talk to PostgreSQL synchronously, so every data-backed endpoint (login, appointments, clinics, and so on) would stop working.
