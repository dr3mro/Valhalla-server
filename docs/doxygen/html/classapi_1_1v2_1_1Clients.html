Detailed Description

REST controller for client accounts (users and providers).

A {clientType} path segment selects a ClientController<User> or ClientController<Provider> from a variant registry. create and login are INSECURE (no token required); all other routes are SECURE and use the identity attributes inserted by Auth. Most handlers delegate to executeControllerMethod; several provide a drogon::Task coroutine path when DatabaseConfig::async is set, and read has a prototype async implementation for users and providers only. Controllers, GateKeeper, DatabaseController and the executor are shared service-locator objects.

Coroutine implementing the prototype async read for a single client entity type T.

Coroutine definition of the prototype async read; see the in-class declaration.

Parses id/schema from the body (400 on malformed JSON), checks read permission via GateKeeper::canRead (permitted when no GateKeeper is registered), validates the read schema, builds SQL with getSqlReadStatement, then co_awaits executeReadQueryCoro. A non-empty result is a success, an empty result and other failures are 400; DatabaseBusy maps to 503 and other exceptions to 500.

Template Parameters
