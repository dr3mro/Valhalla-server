Detailed Description

Client-specific handler that layers password hashing, sessions and account state over the generic CRUDS flow.

Declares ClientController<T>, which inherits storage from EntityController<T> and the account contract from ClientControllerBase. Simple operations (Read/Search) just forward to the base. Create/Update are special: they run on a PasswordWorker because hashing is deliberately slow. Login/Logout and account state go through GateKeeper. The definitions and instantiations live in clientcontroller.cpp.

WHY THIS FILE MATTERS IN THE SERVER: Accounts need protections that ordinary records do not: passwords must be hashed off the request thread, and sessions must be invalidated when an account is deleted or suspended. This class adds exactly those behaviours on top of the generic entity pipeline. Without it, clients would be treated like any other row and password hashing would block the server's IO threads.
