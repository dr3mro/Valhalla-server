1/**
2 * @file envvars.hpp
3 * @brief Thin protected wrapper around the process environment (getenv/setenv).
4 * @details This small header declares two helper functions that read and write environment
5 * variables, which are name/value pairs stored by the operating system for this running
6 * program. It does no conversion or validation itself; it only fetches the raw text string.
7 * A higher-level class (EnvLoader) builds on top of this to turn that text into numbers,
8 * booleans, and other types the server needs.
9 *
10 * WHY THIS FILE MATTERS IN THE SERVER:
11 * This is the very bottom layer of the configuration system. The server keeps almost every
12 * setting (ports, database credentials, timeouts) in environment variables so deployments can
13 * change behaviour without editing code or rebuilding. EnvVars is the only place that talks
14 * directly to the operating system's environment. EnvLoader calls get() to read values, and
15 * tests call set() to prepare temporary values. Without this file there would be no safe,
16 * uniform way for the rest of the configuration code to reach those settings.
17 *
18 * CONCEPTS TO LEARN (for beginners):
19 * - Environment variables: https://man7.org/linux/man-pages/man7/environ.7.html
20 * - std::optional (a value that may be missing): https://en.cppreference.com/w/cpp/utility/optional
21 *
22 * @author Amr Osman <dr3mro@gmail.com>
23 * @date 2026-11-16
24 */

32 * @class EnvVars
33 * @brief Thin protected wrapper around the process environment (getenv/setenv).
34 *
35 * @details Provides the raw accessors on which EnvLoader builds its typed conversions.
36 * The helpers are static and protected so only derived configuration types (or test code
37 * deriving from them) can read or modify the environment; callers are expected to use the
38 * EnvLoader overloads instead.
39 *
40 * @note The set of environment variables is process-global. Reading is safe while no other

42 * start, not for the request path.
43 * @see EnvLoader
44 */

49 /**
50 * @brief Reads a raw environment variable.
51 * @details Asks the operating system for the value stored under @p key. In plain words:
52 * "is there a variable with this name, and if so what text does it hold?" The answer is
53 * wrapped in an optional so that "not set" is clearly different from "set to empty text".
54 * @param[in] key Variable name.
55 * @return The value as a string, or std::nullopt when the variable is not set.
56 */
57 static std::optional<std::string> get(const std::string& key); // Returns the raw text, or an empty optional when the name is not present.

60 /**
61 * @brief Sets (or overwrites) an environment variable in the current process.
62 * @param[in] key Variable name.
63 * @param[in] value New value.
64 * @note On failure an error message is logged; the call does not throw.
65 * @warning Mutating the process environment is not synchronized with other threads.

67 * protected method; production configuration is read-only.
68 */
69 static void set(const std::string& key, const std::string& value); // Stores value under key; used by tests to fake settings, not on the request path.
