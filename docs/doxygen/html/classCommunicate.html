Detailed Description

Thin static-only wrapper around libcurl for outbound HTTP calls.

Builds server:port/path, sends a JSON content-type header and performs either a GET or a POST with the supplied body. There is no instance state: each call creates and cleans up its own CURL handle, and failures are reported to the console via Message and signalled to the caller by an empty optional rather than by an exception.

Note
Only GET and POST are supported; all calls are blocking.
