Detailed Description

Implementation of Server: Drogon configuration, request hooks, and shutdown sequencing.

This file turns the Server declaration into working code. It builds the Drogon application — listener, thread count, log level, a custom 404 page — and registers two global hooks: one that answers CORS preflights and rejects unusual HTTP methods before routing, and one that adds CORS headers to every response. It also prints the startup banner and, after the event loops stop, drains the database and password worker pools in a safe order.

WHY THIS FILE MATTERS IN THE SERVER: This is the file that actually boots the web server. main() calls Server::run(), and the code here is what opens the listening port and starts Drogon's event loops so HTTP requests can be served. It also contains the two cross-cutting request rules (CORS and allowed methods) that apply to every endpoint, so individual controllers do not have to repeat them. Finally, it owns the shutdown order; without it, worker threads could be destroyed while they still had queued work, causing crashes at exit.

  • Lambda expressions (the inline anonymous functions used as callbacks): https://en.cppreference.com/w/cpp/language/lambda
  • Move semantics and std::move: https://en.cppreference.com/w/cpp/utility/move
  • Drogon's application and advice hooks: https://github.com/drogonframework/drogon
