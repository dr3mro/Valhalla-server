Detailed Description

REST controller for appointment records of the appointment-providing entities.

A {entityType} path segment (clinics, pharmacies, laboratories, radiologycenters) selects a concrete AppointmentController<T> from a std::variant registry. Every handler builds a callback that maps the controller's numeric status to a standard JSON HTTP response and constructs a Requester from the "clientID"/"clientGroup" attributes inserted by the Auth filter, so all routes are SECURE. When DatabaseConfig::async is set the *Async controller methods are awaited in a drogon::Task coroutine; otherwise executeControllerMethod runs the blocking permission check and query on the shared DbExecutor. Controllers and the executor are shared service-locator objects.
