Detailed Description

Entity for service/organisation tables (clinics, pharmacies, laboratories, ...).

Adds builders that mutate the JSONB "staff" array of a service row to add or remove a nominee, plus a static query used by PermissionManager to read a service's owner/admin/staff. CRUD statements remain inherited from Entity.

Note
The staff builders bind the nominee and entity ids through Binder; the static permission query interpolates the service name and id into its text and is used as a permission cache key.
See also
Entity, api::v2::Types::StaffData

Builds the permission lookup for a service row by id.

Returns the owner/admin/staff columns used by PermissionManager to authorise service-level actions. The table name and id are formatted into the query text rather than bound; the resulting text also serves as the permission cache key.

Builds the UPDATE that appends a nominee id to the service's Doctors staff array.

Uses jsonb_set on the mjson payload path {payload,providers,Doctors}, concatenating the nominee id as a JSON text value. Both the nominee id (as text) and the entity id are bound.

Builds the UPDATE that removes a nominee id from the service's Doctors staff array.

Rebuilds the array with jsonb_agg over the elements that do not equal the bound nominee id (as JSON text). The nominee and entity ids are bound in a fixed order.
