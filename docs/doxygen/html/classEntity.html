Detailed Description

Concrete Base implementation that turns a CRUD value type into SQL statements.

An Entity pairs one api::v2::Types::EntityType alternative with the database table (also used as the permission "group") it belongs to. The five Base builders are thin adapters that create a fresh Binder and delegate to the build* helpers below; each helper owns the details of one statement shape. Instances are created for each request and are immutable after construction (both the variant and the table name are const), except for the id cached by check_id_exists(). All parameter values go through Binder::bind, so they never appear in the SQL text.

Note
Neither copy nor move is allowed; construct the entity in place for the request that uses it.
See also
Base, api::v2::Types::EntityType
Note
For a beginner: the five getSql*Statement functions are the public "adapters"; each makes a Binder and calls one private-ish build* helper. Splitting them this way keeps the public API small while letting each SQL shape be written and read on its own.

Builds the INSERT statement from a Create_t payload.

Iterates the JSON object range, binding every value and using the (sorted) keys as column names. An explicit id from the caller is inserted; otherwise "id" is erased so the database assigns it, which also prevents a client from choosing its own primary key.

template<typename Binder>
std::optional< std::string > Entity::buildSearchStatement ( Binder & binder)
inlineprotected

Builds the paginated ILIKE search statement for the table's _safe view.

The keyword is wrapped in %...% for substring matching and bound together with a limit of (requested limit + 1) and the offset; the extra row lets callers detect a further page. filter, order_by and direction are SQL identifiers and are written into the text, so they must already have been validated by Search_t.

Template Parameters
BinderBinder-like type providing bind().
Parameters
[in,out]binderAppends keyword, limit and offset and returns their placeholders.
Returns
The SELECT text, or std::nullopt if an exception occurs.
Note
Bindings are made into named locals first because argument evaluation order is unspecified; the placeholder numbering must follow a fixed order.
