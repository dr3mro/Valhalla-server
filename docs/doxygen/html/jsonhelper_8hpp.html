Detailed Description

Conversions between JsonCpp, jsoncons and response strings.

Declares the JsonHelper class, a stateless toolbox with three static functions: one wraps a text message into a JsonCpp object with a "Message" key, and two others turn JsonCpp or jsoncons values into pretty-printed strings. All constructors and assignments are deleted, so the class exists purely as a namespace for its helper functions.

WHY THIS FILE MATTERS IN THE SERVER: The codebase uses two JSON libraries: JsonCpp for HTTP response bodies (via Drogon) and jsoncons for validation work. This helper bridges them and gives the rest of the server one consistent way to build simple status/error bodies and to turn JSON values into readable text. Without it, each caller would duplicate the wrapping and stringifying logic and the output shape could drift.

CONCEPTS TO LEARN (for beginners):

  • Static member functions: https://en.cppreference.com/w/cpp/language/static#Static_member_functions
  • Deleted functions (= delete): https://en.cppreference.com/w/cpp/language/member_functions#Deleted_functions
  • Function overloading (two stringify versions): https://en.cppreference.com/w/cpp/language/overload_resolution
