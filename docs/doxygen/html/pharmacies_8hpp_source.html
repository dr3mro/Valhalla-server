2 * @file pharmacies.hpp
3 * @brief Service entity bound to the `pharmacies` table (a pharmacy service provider).
4 * @details This header declares the Pharmacies class, a very small C++ type that stands for one pharmacy in the
5 * `pharmacies` database table. It holds almost no logic of its own. It only names the table and lets its
6 * parent class Service do the real work of building SQL statements. You create one by passing in a data
7 * wrapper made from a client request, and the parent stores that wrapper for later use.
8 *
9 * WHY THIS FILE MATTERS IN THE SERVER:
10 * Pharmacies is one of the "service provider" types in the server, next to laboratories and radiology centres. When a
11 * client creates, reads, updates or deletes a pharmacy, or manages its staff, the route layer picks this class as
12 * ServiceController<Pharmacies> / StaffController<Pharmacies>. Those controllers call the inherited methods from
13 * Service and Entity, which produce the actual SQL. The class also publishes the table name so PermissionManager can
14 * check that the requesting staff member is allowed to change this service. Without this file there would be no C++
15 * type tying the `pharmacies` table to the generic CRUD machinery, so pharmacy endpoints could not work.
16 *
17 * CONCEPTS TO LEARN (for beginners):
18 * - static constexpr: a value fixed at compile time that belongs to the class, not to one object. https://en.cppreference.com/w/cpp/language/static
19 * - JSON: a text format used to carry request data; this project uses the jsoncons library to read it. https://jsoncons.github.io/jsoncons/
20 * - Template (`template <typename T>`): a blueprint that works with whatever data type the caller supplies. https://en.cppreference.com/w/cpp
21 *
22 * @author Amr Osman <dr3mro@gmail.com>
23 * @date 2026-11-16
24 */
