2 * @file pharmacies.hpp
3 * @brief Service entity bound to the `pharmacies` table (a pharmacy service
4 * provider).
5 * @details This header declares the Pharmacies class, a very small C++ type
6 * that stands for one pharmacy in the `pharmacies` database table. It holds
7 * almost no logic of its own. It only names the table and lets its parent class
8 * Service do the real work of building SQL statements. You create one by
9 * passing in a data wrapper made from a client request, and the parent stores
10 * that wrapper for later use.
11 *
12 * WHY THIS FILE MATTERS IN THE SERVER:
13 * Pharmacies is one of the "service provider" types in the server, next to
14 * laboratories and radiology centres. When a client creates, reads, updates or
15 * deletes a pharmacy, or manages its staff, the route layer picks this class as
16 * ServiceController<Pharmacies> / StaffController<Pharmacies>. Those
17 * controllers call the inherited methods from Service and Entity, which produce
18 * the actual SQL. The class also publishes the table name so PermissionManager
19 * can check that the requesting staff member is allowed to change this service.
20 * Without this file there would be no C++ type tying the `pharmacies` table to
21 * the generic CRUD machinery, so pharmacy endpoints could not work.
22 *
23 * CONCEPTS TO LEARN (for beginners):
24 * - static constexpr: a value fixed at compile time that belongs to the class,
25 * not to one object. https://en.cppreference.com/w/cpp/language/static
26 * - JSON: a text format used to carry request data; this project uses the
27 * jsoncons library to read it. https://jsoncons.github.io/jsoncons/
28 * - Template (`template <typename T>`): a blueprint that works with whatever
29 * data type the caller supplies. https://en.cppreference.com/w/cpp
30 *
31 * @author Amr Osman <dr3mro@gmail.com>
32 * @date 2026-11-16
33 */

50 * machinery to one database table. CRUD/search statement generation and staff
51 * management are entirely inherited; this class only fixes the table name and
52 * exposes it to the permission layer. Instances are built from one of the
53 * api::v2::Types data wrappers (for example Create_t or Read_t), which Entity
