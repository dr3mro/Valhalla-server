Detailed Description

Definitions and explicit instantiations for ClinicController<T> over clinic-service entity types.

Constrained *Impl helpers select behaviour per type: client-supplied ids for most entities, generic creation for Patient/Visits, and "not implemented" responses for unsupported Delete/Search/GetVisits.

WHY THIS FILE MATTERS IN THE SERVER: This is where the type-specific clinic rules are implemented. The non-Patient create path carefully parses a client-supplied id (with its own checks so bad input becomes a 400, not a 500), while Patient/Visits reuse the generic flow. Unsupported actions get an explicit client error instead of a bogus database call. The public methods at the bottom simply forward to the right helper, and the instantiations make all clinic types linkable.
