1/**
2 * @file callback.hpp
3 * @brief Shared completion-callback type for the API and its workers.
4 * @details Defines one macro, CALLBACK_, that names a single function-signature
5 * type used everywhere a piece of work needs to report its result when
6 * it finishes. The signature carries an integer status code and a text
7 * body, which matches how the REST API answers requests. Because it is
8 * a macro (a textual shortcut handled by the preprocessor), every file
9 * that uses it gets the exact same type without repeating the long
10 * definition.
11 *
12 * WHY THIS FILE MATTERS IN THE SERVER:
13 * This is the small glue that lets the HTTP layer and the background workers
14 * agree on how to talk back. A route handler passes a CALLBACK_ into a
15 * controller; the controller queues work on an executor and later "calls back"
16 * with a status (see api::v2::Http::Status) and a JSON string. Without this
17 * shared type, each layer would invent its own signature and the pieces would
18 * no longer fit together. It is included by controllers, routes and helpers
19 * across the API layer.
20 *
21 * CONCEPTS TO LEARN (for beginners):
22 * - std::function:
23 * https://en.cppreference.com/w/cpp/utility/functional/function
24 * - Lambda expressions: https://en.cppreference.com/w/cpp/language/lambda
25 * - Preprocessor macros: https://en.cppreference.com/w/cpp/preprocessor/replace
26 *
27 * @author Amr Osman <dr3mro@gmail.com>
28 * @date 2026-11-16
29 */
