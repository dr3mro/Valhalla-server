Detailed Description

Appends values to a pqxx::params and hands back the matching SQL placeholders.

Construction clears the supplied container, so each fresh Binder restarts numbering at $1 for one statement. Routing every value through bind() is what keeps callers from concatenating untrusted data into SQL text.

Note
Holds a borrowed reference to the params container and must not outlive it.
For a beginner: this is a helper struct that derived builders create on the stack for one SQL statement. It remembers a running counter so the first value becomes $1, the second $2, and so on, which is exactly what PostgreSQL expects in the prepared query.
