1/**
2 * @file databasehandler.cpp
3 * @brief Implementation for databasehandler: Delegates to the pool-taking
4 * constructor after resolving the pool from the Store.
5 * @details This file implements the small RAII lease class. The default
6 * constructor finds the shared DatabaseConnectionPool in the Store and hands it
7 * to the pool-taking constructor, which immediately leases a connection. The
8 * destructor returns that connection, and get_connection()/reconnect_all()
9 * simply expose the lease or forward a request to the pool.
10 *
11 * WHY THIS FILE MATTERS IN THE SERVER:
12 * It is the implementation behind every synchronous database call: controllers
13 * and the watchdog create a DatabaseHanndler, and these few functions are what
14 * actually acquire and release the connection. Because the return to the pool
15 * happens in the destructor, exceptions in query code cannot strand a
16 * connection. Without this file the lease abstraction would be declared but
17 * undefined, so no synchronous request could obtain a connection.
18 *
19 * CONCEPTS TO LEARN (for beginners):
20 * - RAII (acquire in constructor, release in destructor):
21 * https://en.cppreference.com/w/cpp/language/raii
22 * - Delegating constructors (one constructor calls another):
23 * https://en.cppreference.com/w/cpp/language/initializer_list
24 * - std::move (transfer ownership without copying):
25 * https://en.cppreference.com/w/cpp/utility/move
26 * - std::shared_ptr: https://en.cppreference.com/w/cpp/memory/shared_ptr
27 *
28 * @author Amr Osman <dr3mro@gmail.com>
29 * @date 2026-11-16
30 */

53/**
54 * Leases one connection immediately so the handler always owns a valid lease.
55 * pool: Pool to lease from; stored so the destructor can return the connection.
56 * Throws DatabaseBusy: If the pool's acquire timeout expires.
57 */
58DatabaseHanndler::DatabaseHanndler(std::shared_ptr<DatabaseConnectionPool> pool)
59 : databaseConnectionPool(std::move(pool)) {
60 db_ptr = databaseConnectionPool->get_connection();
61} // Store the pool, then lease a connection immediately; if none is free this
62 // throws, so a half-built handler never exists.
63
64/**
65 * @brief Returns the leased connection to the pool, if any is still held.
66 * @details The null check makes destruction safe even after a connection was
67 * moved out.
68 */
69DatabaseHanndler::~DatabaseHanndler() {
70 // Only return a real lease; a null pointer means it
71 // was already moved away.
72 if (db_ptr != nullptr) {
73 databaseConnectionPool->return_connection(
74 std::move(db_ptr)); // Hand the connection back, waking one waiter
75 // in the pool.
76 }
77}
