1/**
2 * @file databasehandler.cpp
3 * @brief Implementation for databasehandler: Delegates to the pool-taking constructor after resolving the pool from the Store.
4 * @details This file implements the small RAII lease class. The default constructor finds the
5 * shared DatabaseConnectionPool in the Store and hands it to the pool-taking
6 * constructor, which immediately leases a connection. The destructor returns that
7 * connection, and get_connection()/reconnect_all() simply expose the lease or forward
8 * a request to the pool.
9 *
10 * WHY THIS FILE MATTERS IN THE SERVER:
11 * It is the implementation behind every synchronous database call: controllers and the
12 * watchdog create a DatabaseHanndler, and these few functions are what actually acquire and
13 * release the connection. Because the return to the pool happens in the destructor, exceptions
14 * in query code cannot strand a connection. Without this file the lease abstraction would be
15 * declared but undefined, so no synchronous request could obtain a connection.
16 *
17 * CONCEPTS TO LEARN (for beginners):
18 * - RAII (acquire in constructor, release in destructor): https://en.cppreference.com/w/cpp/language/raii
19 * - Delegating constructors (one constructor calls another): https://en.cppreference.com/w/cpp/language/initializer_list
20 * - std::move (transfer ownership without copying): https://en.cppreference.com/w/cpp/utility/move
21 * - std::shared_ptr: https://en.cppreference.com/w/cpp/memory/shared_ptr
22 *
23 * @author Amr Osman <dr3mro@gmail.com>
24 * @date 2026-11-16
25 */

55 databaseConnectionPool->return_connection(std::move(db_ptr)); // Hand the connection back, waking one waiter in the pool.
