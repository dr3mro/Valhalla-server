Detailed Description

Stateless facade for emitting coloured status messages.

Severity helpers (Debug through Critical) write through trantor::Logger, so they flow into the configured Logger/spdlog sinks. ConfMessage and InitMessage are startup/status notices that instead print directly to stdout with a [Project Valhalla] prefix. All methods are static; instances carry no state.
