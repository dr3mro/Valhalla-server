Detailed Description

Timing middleware that logs how long a request took to produce its response.

Part of both the INSECURE and SECURE chains. It records a steady_clock start, passes the request onward, and measures the interval in the return-path callback when the downstream handler's response propagates back out. The result is logged with request IP, method, status and path; the response is then forwarded unchanged. Stateless and safe for concurrent requests: all per-request state lives in the callback capture.

Start the timer and install a return-path callback that logs elapsed milliseconds.

Invoked by Drogon on its IO thread. The callback passed to nextCb runs when the response comes back from later middleware/handlers, so the measurement covers the whole downstream chain. The response is forwarded untouched to mcb.
