Detailed Description

ClientData_t for updating a client: validates an update schema with a caller-supplied rule.

Unlike CreateClient_t it does not hash passwords; the validation rule is provided by the caller because different update endpoints permit different field sets.

Note
Unlike CreateClient_t this type does not re-hash the password: the generic Update path marks password as ASSERT_IMMUTABLE, so no new password can arrive here.
