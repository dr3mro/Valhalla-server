Detailed Description

REST controller for managing staff membership of service entities.

A {serviceType} path segment selects a StaffController<T> from a variant registry (clinics, pharmacies, laboratories, radiologycenters). Handlers use the shared callback pattern to map controller status codes to JSON HTTP responses, build a Requester from Auth attributes, and run async coroutines or the DbExecutor-backed dispatch according to DatabaseConfig::async. All routes are SECURE. Controllers and the executor are shared service-locator objects.

Note
Drogon prepends its controller path (/api/v2/staff) to the METHOD_ADD paths below, so the effective URLs contain a doubled "staff" segment (e.g. /api/v2/staff/.../staff/invite).
