Detailed Description

Thin protected wrapper around the process environment (getenv/setenv).

This small header declares two helper functions that read and write environment variables, which are name/value pairs stored by the operating system for this running program. It does no conversion or validation itself; it only fetches the raw text string. A higher-level class (EnvLoader) builds on top of this to turn that text into numbers, booleans, and other types the server needs.

WHY THIS FILE MATTERS IN THE SERVER: This is the very bottom layer of the configuration system. The server keeps almost every setting (ports, database credentials, timeouts) in environment variables so deployments can change behaviour without editing code or rebuilding. EnvVars is the only place that talks directly to the operating system's environment. EnvLoader calls get() to read values, and tests call set() to prepare temporary values. Without this file there would be no safe, uniform way for the rest of the configuration code to reach those settings.

CONCEPTS TO LEARN (for beginners):

  • std::optional (a value that may be missing): https://en.cppreference.com/w/cpp/utility/optional
