Detailed Description

A short-lived, thread-safe cache of permission data read from the database. (Originally: "Idle-expiry cache for permission lookups, keyed by the generated permission.").

This header defines a template cache that remembers the answer to a permission query for a while. Each use renews the entry's lifetime; unused entries expire. A generation counter prevents a slow read from putting stale data back after the cache has been flushed.

WHY THIS FILE MATTERS IN THE SERVER: Permission checks happen on almost every request. Reading them from PostgreSQL each time would be slow, so PermissionManagerPrivate asks this cache first. Without it, authorization would mean a database round-trip on every API call.
