Detailed Description

Owns one synchronous PostgreSQL connection used by the synchronous database path.

A Database wraps a single pqxx::connection and offers the query helpers used by controllers through a DatabaseHanndler lease. Instances are constructed and owned by DatabaseConnectionPool, which hands them out one borrower at a time; callers never construct one directly. The constructor validates the connection with SELECT 1 and caches its connection string so reconnect() can rebuild it later.

Thread-safety: the wrapped connection is used by one borrower at a time as enforced by the pool, so no internal locking is performed. Non-copyable and non-movable: ownership stays with the pool's std::shared_ptr.

Note
The constructor tolerates a null connection (no validation performed and an empty cached connection string); in normal operation the pool passes a validated connection.
See also
DatabaseConnectionPool, DatabaseHanndler

Checks whether a row exists using a parameterised EXISTS query. Table and column are passed through quote_name (identifiers cannot be bound as parameters); only the value is bound. The transaction scope is closed before the result is read so no idle transaction is left open on the connection. table: Table name. column: Column name. value: Value bound to $1. Returns true if the row exists; false if not, or if the query threw. Note: Query failures are swallowed and reported as false (see the header note).

Runs the statement through TransactionType (committed only when it is a pqxx::work). For a json array every result row is appended; for a single json object only the first row is returned.

Executes a parameterised query and converts result rows to JSON. Commits the transaction only when TransactionType is pqxx::work; a pqxx::nontransaction simply ends at scope exit. Columns are converted by PostgreSQL type OID, with unhandled types falling back to a string. Template parameter jsonType: jsoncons::json (returns the first row) or jsoncons::json::array (returns all rows); any other type is rejected by a static_assert. Template parameter TransactionType: Transaction wrapper used for the execution. query: SQL text with $1, $2, ... placeholders. params: Values bound to those placeholders. Returns The converted value, or std::nullopt if any exception was caught. Note: For the single-object specialisation an empty result yields a default-constructed JSON value, not std::nullopt (only exceptions produce std::nullopt).

Replaces the wrapped connection with a fresh one built from the cached string.

Rebuilds the wrapped connection from the string cached at construction.

Returns
The result of check_connection() on the new connection; false on failure.
Note
Not thread-safe: callers must ensure no query is in flight. The old connection is released when the shared_ptr is replaced.
Returns
The health check result of the new connection; false if creation or check failed.

The old connection is dropped when the shared_ptr is reassigned. The failure path is logged as critical. Not thread-safe: the caller must own the Database exclusively (see DatabaseConnectionPool::reconnect_all and the watchdog).
