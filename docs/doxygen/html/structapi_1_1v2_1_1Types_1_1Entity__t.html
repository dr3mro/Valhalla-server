Detailed Description

template<typename S>
class api::v2::Types::Entity_t< S >

Immutable payload-plus-optional-id base for the CRUD operation value types.

Stores the operation's data (a JSON object for create/update, a column set for read, a sentinel for delete/data) together with an optional primary key. The payload and id are const, so an instance is a fixed description of one requested operation. Concrete types below are empty specialisations that choose S and expose construction appropriate to the operation.
