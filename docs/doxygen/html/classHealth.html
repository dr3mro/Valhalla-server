Detailed Description

Case entity for the patients_health table (a patient's health record).

A thin value type that binds the generic Case/Entity CRUD machinery to one table. The table's primary key is the patient id (a foreign key to patients with ON DELETE CASCADE), so there is at most one health record per patient. SQL generation itself is inherited; this class fixes the table name and the patient table used to resolve the owning clinic during create-authorisation. The static getPermissionsQueryFor* helpers are taken as function pointers by PermissionManager::canCreate/canRead/canUpdate/ canDelete for api::v2::Case_t T. The type is registered in the clinic route registry as ClinicController<Health> under the health serviceType. Ownership: the data wrapper is copied into Entity and is const thereafter; no mutable state and no locking of its own. Copy and move are deleted by Case.

Note
No default constructor: Entity needs a data wrapper to build statements from.

◆ getPermissionsQueryForCreate()

std::optional< std::string > Health::getPermissionsQueryForCreate ( const std::optional< jsoncons::json > & data_j)
inlinestatic

Builds the SQL that resolves the owning clinic for a create request.

Reads the patient id from data_j using CREATE_KEY and delegates to the Case base, which joins clinics with patients on clinic_id. PermissionManager runs the returned SELECT before the insert to check owner/admin/staff rights; no insert is performed here.

Parameters
[in]data_jCreate payload; must be engaged and contain an unsigned-integer CREATE_KEY (the optional is dereferenced without a has_value() check).
Returns
The SELECT statement, or std::nullopt if reading or converting the key throws; the exception is logged via CRITICALMESSAGE.
