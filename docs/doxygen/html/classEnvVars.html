Detailed Description

Thin protected wrapper around the process environment (getenv/setenv).

Provides the raw accessors on which EnvLoader builds its typed conversions. The helpers are static and protected so only derived configuration types (or test code deriving from them) can read or modify the environment; callers are expected to use the EnvLoader overloads instead.

Note
The set of environment variables is process-global. Reading is safe while no other thread mutates the environment; mutation is intended for setup/test code before threads start, not for the request path.

std::optional< std::string > EnvVars::get ( const std::string & key)
staticprotected

Reads a raw environment variable.

Asks the operating system for the value stored under key. In plain words: "is there a variable with this name, and if so what text does it hold?" The answer is wrapped in an optional so that "not set" is clearly different from "set to empty text".

Parameters
[in]keyVariable name.
Returns
The value as a string, or std::nullopt when the variable is not set.
