Detailed Description

Base class for all entities in the application. Provides common functionality for creating, reading, updating, deleting, and searching entities. Derived classes must implement the virtual functions to provide the SQL statements for each operation.

The interface separates deciding what SQL to run from executing it: a caller asks an entity for a statement plus its bound parameters and hands both to the database layer. Every builder returns SQL containing only $1, $2, ... placeholders and appends the actual values to the caller-supplied pqxx::params, so column values are never written into the SQL text. A builder returns std::nullopt when it cannot produce a usable statement.

Note
The destructor is virtual because entities are used polymorphically through this interface.
See also
Entity, Binder
Note
For a beginner: "virtual" means the call is decided at runtime, so a Base pointer can reach the correct derived-class version of each function. "= 0" means this class gives no body and forces children to provide one; that is what makes Base abstract (not instantiable).
