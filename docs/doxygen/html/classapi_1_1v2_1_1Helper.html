Detailed Description

Factory for the standard JSON HTTP responses used by the v2 controllers and filters.

All members are static; the class is a namespace-like utility with no state. The response callbacks are consumed (moved from) exactly once to deliver the reply. failure/error responses wrap the message in a JSON object with a "Status" field, while success responses pass the message through as-is. Every reply is JSON with a 503 response additionally carrying Retry-After: 1.

Note
Copyable but non-movable; construction is unrestricted but meaningless since there is no instance state.
