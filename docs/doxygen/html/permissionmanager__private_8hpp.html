Detailed Description

The behind-the-scenes helper functions used by PermissionManager. (Originally: "Implementation helpers shared by the PermissionManager authorization overloads.").

This header declares static utilities that interpret the permission JSON (owner id, admin id and staff entries), compare the requester's identity, validate creation payloads, and fetch/cache permissions. The class is just a namespace-like container; it holds no data.

WHY THIS FILE MATTERS IN THE SERVER: PermissionManager delegates the real work here, so the same rules are applied consistently to services, cases and appointments. Without these helpers the public manager would have to repeat database lookups and JSON parsing in every overload.
