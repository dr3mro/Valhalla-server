Detailed Description

template<typename T, typename ClockT = std::chrono::steady_clock>
class MemCache< T, ClockT >

Bounded LRU cache whose entries expire after a configurable TTL.

Keys map to iterators into a std::list, giving O(1) lookup, recency promotion and eviction. A background thread periodically erases expired entries; insert() independently evicts the least recently used entry when capacity is reached. All public operations and the cleaner share a single mutex, so they are safe to call concurrently.

The cleaner thread holds a raw pointer to this. Move operations stop and join both the source's and destination's cleaners before touching state; the destructor does the same before members are destroyed.

Template Parameters
TValue type; stored and returned by value, so it must be copyable.
ClockTClock exposing a static now(); injectable so tests can use a manually advanced clock instead of waiting in real time.
Note
get() treats an expired entry as a miss but does not erase it; physical removal is left to the cleaner. remove() does not check expiry.

void MemCache< T, ClockT >::cleanExpiredEntries ( )
inlineprivate

Cleaner loop that periodically erases all expired entries.

Waits on cleanerCv_ with a one-second timeout; a notification from destruction or a move wakes it immediately so it can observe stopCleaner_ and exit. Otherwise it scans the entire list because move-to-front can leave expired entries away from the back.
