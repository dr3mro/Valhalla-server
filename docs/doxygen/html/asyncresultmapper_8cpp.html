Detailed Description

Implementation for asyncresultmapper: Converts one row into a JSON object using name- and value-based type inference.

This file implements the row-to-JSON conversion. For each column it checks whether the value is SQL NULL, whether the column is a known boolean or identifier field, whether the text looks like JSON, and otherwise keeps the text as a string. The first-row and all-row helpers simply call the row mapper in a loop or at index zero.

WHY THIS FILE MATTERS IN THE SERVER: Async controller methods receive a Drogon Result and must return JSON to the HTTP layer. This file performs that translation and deliberately mirrors the older synchronous Database::executeQuery outcomes: nulls stay null, the active flag is a boolean, ids are numbers, and json/jsonb columns become nested JSON. Because parsing errors are caught and the raw text is kept, one unusual database value cannot crash a whole list response. Without this file, the async database path could not produce the same JSON contract that the rest of the API relies on.
