Detailed Description

Declaration of Server, the application-level owner of Drogon setup and startup/shutdown sequencing.

This header declares the Server class. The class gathers everything needed to start the application: a snapshot of the configuration, the shared singletons, and the small filter/middleware objects used by the two global request hooks. Its constructor caches those objects; run() performs the actual Drogon setup, blocks in the event loop, and then shuts the worker pools down in a safe order.

WHY THIS FILE MATTERS IN THE SERVER: Server is the single coordinator between the tiny main() function and the rest of the application. main() only creates a Server and calls run(); everything else — printing the banner, choosing the listening port and thread count, adding CORS and method checks to requests, and draining the database and password workers on exit — is either done here or started from here. Without this header there would be no agreed interface for main() to call, and the startup/shutdown ordering rules would have nowhere to live.
