Detailed Description

Implementation for watchdog: Starts the monitoring thread that periodically checks a pooled connection.

This file implements WatchDog. The constructor guards against a pre-existing thread and then launches a lambda that loops while the atomic flag is set. Each cycle leases a connection with an RAII handler, checks it, and on failure reconnects it and asks the pool to reconnect all idle links. DatabaseBusy and other exceptions are caught and followed by an interval sleep. The destructor clears the flag and joins the thread before the watchdog object disappears.

WHY THIS FILE MATTERS IN THE SERVER: It is the server's automatic recovery mechanism for the synchronous database path. A database restart or a dropped socket is detected here within one second and repaired without any request failing permanently. Because the monitor leases its connection through a DatabaseHanndler, it also participates in the same pool and back-pressure rules as regular requests. Without this file, stale connections would keep failing until manual intervention.

  • Exceptions and catch blocks: https://en.cppreference.com/w/cpp/language/try_catch
