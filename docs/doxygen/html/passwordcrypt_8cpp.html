Detailed Description

The implementation of the password hashing and checking wrapper. (Originally: "Implementation for passwordcrypt: Ensures libsodium is initialized before any hashing or verification.").

This file sets up libsodium once, turns a plain password into a self-describing Argon2id hash, and checks plain passwords against stored hashes. It understands both the new Argon2id format and the older scrypt format so old accounts are not locked out.

WHY THIS FILE MATTERS IN THE SERVER: This is where the actual password cryptography happens. The session manager calls these functions (through PasswordWorker) during login and logout. If this code were missing, the server could not safely store passwords or prove that a supplied password is correct, so authentication would be impossible.

CONCEPTS TO LEARN (for beginners):

  • Argon2id explained: https://en.wikipedia.org/wiki/Argon2

  • OWASP password storage advice: https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html
