Detailed Description

Abstract contract for client (User/Provider) handlers: CRUDS plus session and account-state operations.

Declares ClientControllerBase, a pure interface for accounts that can log in. It starts with the usual CRUDS set and adds authentication (Login/Logout), account state (Suspend/Activate), password reset and service lookup. Every method is pure virtual (= 0), so a concrete class must implement all of them.

WHY THIS FILE MATTERS IN THE SERVER: Clients (users and providers) need more than plain record storage: they need sessions and a logged-in state. This interface is what the HTTP routing layer programs against for those endpoints. The concrete ClientController (see clientcontroller.hpp) implements it by reusing EntityController for the storage part and delegating sessions to GateKeeper. Without this contract the auth endpoints and the generic entity endpoints would not line up.
