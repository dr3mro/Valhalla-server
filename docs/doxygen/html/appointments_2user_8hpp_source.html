18 * CONCEPTS TO LEARN (for beginners):

20 * - Static constexpr member: a compile-time constant stored on the class,
21 * usable without an object.
22 * - One Definition Rule: two different classes with the same name in the same
23 * namespace will clash if both headers are included in one translation unit;
24 * that is the caveat noted for this file.
