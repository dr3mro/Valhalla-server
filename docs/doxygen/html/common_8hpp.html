Detailed Description

Safely parse a numeric id query parameter, replying 400 on failure.

This header holds the small pieces of code that almost every v2 route reuses. First it defines the filter/middleware name macros (RATELIMIT, AUTH, ELAPSED, INSECURE, SECURE) that controllers pass to Drogon's METHOD_ADD. It also provides parseIdParam, which turns an "id" query parameter into a number without letting an exception crash the request. Finally it provides executeControllerMethod, the shared helper that calls a controller, adapts its numeric reply into an HTTP JSON response, and moves slow database work off the IO thread.

WHY THIS FILE MATTERS IN THE SERVER: Every REST controller in this API includes this header. It is the common plumbing between the HTTP layer (Drogon) and the business layer (the controllers/entities). The route controllers call parseIdParam and executeControllerMethod; those in turn use Helper for JSON responses, DbExecutor for background work and GateKeeper-provided attributes for identity. Without this file each of the seven controllers would have to duplicate dozens of lines of tricky error handling and threading.

CONCEPTS TO LEARN (for beginners):

  • HTTP filters/middleware: https://drogon.docsforge.com/master/filter/
  • Query parameters: values appended to a URL after "?" (e.g. ?id=42).
  • C++ templates: https://en.cppreference.com/w/cpp/language/templates
  • std::optional: https://en.cppreference.com/w/cpp/utility/optional
