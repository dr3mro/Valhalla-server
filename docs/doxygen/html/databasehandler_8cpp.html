Detailed Description

Implementation for databasehandler: Delegates to the pool-taking constructor after resolving the pool from the Store.

This file implements the small RAII lease class. The default constructor finds the shared DatabaseConnectionPool in the Store and hands it to the pool-taking constructor, which immediately leases a connection. The destructor returns that connection, and get_connection()/reconnect_all() simply expose the lease or forward a request to the pool.

WHY THIS FILE MATTERS IN THE SERVER: It is the implementation behind every synchronous database call: controllers and the watchdog create a DatabaseHanndler, and these few functions are what actually acquire and release the connection. Because the return to the pool happens in the destructor, exceptions in query code cannot strand a connection. Without this file the lease abstraction would be declared but undefined, so no synchronous request could obtain a connection.

CONCEPTS TO LEARN (for beginners):

  • RAII (acquire in constructor, release in destructor): https://en.cppreference.com/w/cpp/language/raii
  • Delegating constructors (one constructor calls another): https://en.cppreference.com/w/cpp/language/initializer_list
  • std::move (transfer ownership without copying): https://en.cppreference.com/w/cpp/utility/move
  • std::shared_ptr: https://en.cppreference.com/w/cpp/memory/shared_ptr
