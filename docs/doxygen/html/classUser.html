Detailed Description

Client entity for the users table with an id lookup query.

Extends Client and adds a minimal get-services statement that selects the user's id. CRUD and suspend/activate behaviour is inherited unchanged.

std::optional< std::string > User::getSqlGetServicesStatement ( pqxx::params & params)
inline

Builds a query that selects the user id from the users table.

Reads the id from the Data_t payload into client_id and binds it as $1. If the payload has no id, calling value() throws and is caught, yielding std::nullopt.

Parameters
[out]paramsCleared and filled with the bound user id.
Returns
SELECT id FROM users WHERE id = $1, or std::nullopt on failure.
