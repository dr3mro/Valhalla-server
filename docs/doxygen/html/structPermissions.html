Detailed Description

Holds a bitmask of authorization bits and the helpers to combine/test them.

Powers are single-bit flags stored in a uint8_t. Two groups of bits are distinguished by convention: identity bits (USER, PROVIDER, IS_ADMIN, IS_OWNER, IS_SUPER) and capability bits (CAN_READ, CAN_WRITE, CAN_DELETE). A value is a bitwise combination, so a single mask can express roles plus capabilities.

Note
All the test helpers (hasPower(), hasMatch(), operator&) answer "any bit in common", not "all requested bits present".

In everyday words: imagine an 8-switch control panel, one switch per right. Each switch is a power of two (1, 2, 4, 8, ...). Turning on several switches and adding the numbers produces a single value that remembers exactly which switches are on. Testing "is any of these switches on?" is a fast bitwise AND.

Only NONE and CAN_READ/CAN_WRITE/CAN_DELETE are consumed in src/; USER, PROVIDER and IS_SUPER are declared but identity is enforced via Requester string helpers.
