1/**
2 * @file pharmacy.hpp
3 * @brief Appointment entity bound to the pharmacies organisation and its appointment table.
4 * @details This is a thin concrete specialisation of Appointment. It fixes the table name
5 * ("pharmacies_appointments") and organisation name ("pharmacies"), forwards a payload to the
6 * base constructor, and exposes two static permission-query helpers by calling the shared
7 * Appointment implementations. It adds no state or logic of its own.
8 *
9 * WHY THIS FILE MATTERS IN THE SERVER:
10 * Controllers that work with pharmacy appointments construct this class so the generic Appointment
11 * code is tied to the right table and organisation. PermissionManager calls its two static helpers
12 * to authorise appointment actions. Without it, the shared permission logic would have no
13 * pharmacy-specific table and organisation names to work with.
14 *
15 * CONCEPTS TO LEARN (for beginners):
16 * - std::optional: https://en.cppreference.com/w/cpp/utility/optional
17 * - Static constexpr member: a compile-time constant stored on the class, usable without an object.
18 * - Inheritance: deriving from Appointment means this class automatically gets its CRUD builders.
19 *
20 * @author Amr Osman <dr3mro@gmail.com>
21 * @date 2026-11-16
22 */
23
