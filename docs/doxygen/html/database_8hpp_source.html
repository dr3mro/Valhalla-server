2 * @file database.hpp
3 * @brief Owns one synchronous PostgreSQL connection used by the synchronous
4 * database path.
5 * @details This header declares the Database class, a thin wrapper around one
6 * libpqxx connection to a PostgreSQL server. It offers small helpers to check
7 * whether a row exists, probe whether the link is still alive, reconnect after
8 * a failure, run parameterised SQL and turn the returned rows into JSON, and
9 * read table metadata.
10 *
11 * WHY THIS FILE MATTERS IN THE SERVER:
12 * This is the lowest-level building block of the synchronous ("blocking")
13 * database path. DatabaseConnectionPool creates these objects and leases them
14 * out one borrower at a time; DatabaseHanndler holds a lease for the length of
15 * one request; controllers call the query helpers declared here to read and
16 * write application data. Without this class the server would have no way to
17 * talk to PostgreSQL synchronously, so every data-backed endpoint (login,
18 * appointments, clinics, and so on) would stop working.
19 *
20 * CONCEPTS TO LEARN (for beginners):
21 * - RAII: https://en.cppreference.com/w/cpp/language/raii
22 * - std::shared_ptr (a reference-counted smart pointer):
23 * https://en.cppreference.com/w/cpp/memory/shared_ptr
24 * - Move semantics: https://en.cppreference.com/w/cpp/utility/move
25 * - Function templates:
26 * https://en.cppreference.com/w/cpp/language/function_template
27 * - std::optional (a value that may be missing):
28 * https://en.cppreference.com/w/cpp/utility/optional
29 * - if constexpr (compile-time branching):
30 * https://en.cppreference.com/w/cpp/language/if
31 *
32 * @author Amr Osman <dr3mro@gmail.com>
33 * @date 2026-11-16

70/**
71 * @class Database
72 * @brief Owns one synchronous PostgreSQL connection used by the synchronous
73 * database path.
74 * @details A Database wraps a single `pqxx::connection` and offers the query
75 * helpers used by controllers through a DatabaseHanndler lease. Instances are
76 * constructed and owned by DatabaseConnectionPool, which hands them out one
77 * borrower at a time; callers never construct one directly. The constructor
78 * validates the connection with `SELECT 1` and caches its connection string so
79 * reconnect() can rebuild it later.
80 *
81 * Thread-safety: the wrapped connection is used by one borrower at a
82 * time as enforced by the pool, so no internal locking is performed.
83 * Non-copyable and non-movable: ownership stays with the pool's
84 * `std::shared_ptr`.
85 * @note The constructor tolerates a null connection (no validation performed
86 * and an empty cached connection string); in normal operation the pool passes a
87 * validated connection.
88 * @see DatabaseConnectionPool, DatabaseHanndler
89 */
90class Database {
91 public:
92 // Non-copyable/non-movable: the pool owns the shared_ptr, borrowers only
93 // hold a reference to it.
94 Database(const Database&) = delete; // Copying would create a second owner
95 // of the same live connection.
96 Database(Database&&) =
97 delete; // Moving would let a borrower steal the pool's connection.
98 Database& operator=(const Database&) =
99 delete; // Copy-assignment would violate single ownership too.
100 Database& operator=(Database&&) =
101 delete; // Move-assignment would violate single ownership too.

107 * validation failure is logged as critical but does not throw; the object
108 * still exists.
109 * @param[in,out] conn Connection to take ownership of (moved from the
110 * caller).

166 /**
167 * @brief Executes a parameterised query and converts the result rows to
168 * JSON.
169 * @details Runs the statement through TransactionType (committed only when
170 * it is a `pqxx::work`). For a json array every result row is appended; for
171 * a single json object only the first row is returned.
172 * @tparam jsonType `jsoncons::json` (first row) or `jsoncons::json::array`
173 * (all rows).
174 * @tparam TransactionType Transaction wrapper, e.g. `pqxx::nontransaction`
175 * or `pqxx::work`.
176 * @param[in] query SQL text with `$1, $2, ...` placeholders.
177 * @param[in] params Values bound to those placeholders.
178 * @return The converted value, or `std::nullopt` if any exception was
179 * caught.
180 */
181 template <
182 typename jsonType,
183 typename TransactionType> // One template serves both "first row" and
184 // "all rows" and both transaction kinds.
185 std::optional<jsonType> executeQuery(
186 const std::string& query,
187 const pqxx::params& params = {}); // The empty default lets
188 // callers run queries with no
189 // parameters.
