1/**
2 * @file database.hpp
3 * @brief Owns one synchronous PostgreSQL connection used by the synchronous database path.
4 * @details This header declares the Database class, a thin wrapper around one libpqxx
5 * connection to a PostgreSQL server. It offers small helpers to check whether a
6 * row exists, probe whether the link is still alive, reconnect after a failure, run
7 * parameterised SQL and turn the returned rows into JSON, and read table metadata.
8 *
9 * WHY THIS FILE MATTERS IN THE SERVER:
10 * This is the lowest-level building block of the synchronous ("blocking") database path.
11 * DatabaseConnectionPool creates these objects and leases them out one borrower at a time;
12 * DatabaseHanndler holds a lease for the length of one request; controllers call the query
13 * helpers declared here to read and write application data. Without this class the server
14 * would have no way to talk to PostgreSQL synchronously, so every data-backed endpoint
15 * (login, appointments, clinics, and so on) would stop working.
16 *
17 * CONCEPTS TO LEARN (for beginners):
18 * - RAII: https://en.cppreference.com/w/cpp/language/raii
19 * - std::shared_ptr (a reference-counted smart pointer): https://en.cppreference.com/w/cpp/memory/shared_ptr
20 * - Move semantics: https://en.cppreference.com/w/cpp/utility/move
21 * - Function templates: https://en.cppreference.com/w/cpp/language/function_template
22 * - std::optional (a value that may be missing): https://en.cppreference.com/w/cpp/utility/optional
23 * - if constexpr (compile-time branching): https://en.cppreference.com/w/cpp/language/if
24 *
25 * @author Amr Osman <dr3mro@gmail.com>
26 * @date 2026-11-16
27 */

46/**
47 * @class Database
48 * @brief Owns one synchronous PostgreSQL connection used by the synchronous database path.
49 * @details A Database wraps a single `pqxx::connection` and offers the query helpers used by
50 * controllers through a DatabaseHanndler lease. Instances are constructed and owned
51 * by DatabaseConnectionPool, which hands them out one borrower at a time; callers
52 * never construct one directly. The constructor validates the connection with
53 * `SELECT 1` and caches its connection string so reconnect() can rebuild it later.
54 *
55 * Thread-safety: the wrapped connection is used by one borrower at a time as
56 * enforced by the pool, so no internal locking is performed. Non-copyable and
57 * non-movable: ownership stays with the pool's `std::shared_ptr`.
58 * @note The constructor tolerates a null connection (no validation performed and an empty
59 * cached connection string); in normal operation the pool passes a validated connection.
60 * @see DatabaseConnectionPool, DatabaseHanndler
61 */
62class Database
63{
64 public:
65 // Non-copyable/non-movable: the pool owns the shared_ptr, borrowers only hold a reference to it.
66 Database(const Database&) = delete; // Copying would create a second owner of the same live connection.
67 Database(Database&&) = delete; // Moving would let a borrower steal the pool's connection.
68 Database& operator=(const Database&) = delete; // Copy-assignment would violate single ownership too.
69 Database& operator=(Database&&) = delete; // Move-assignment would violate single ownership too.

74 * `connection_string()` for later use by reconnect(). A validation failure is
75 * logged as critical but does not throw; the object still exists.
76 * @param[in,out] conn Connection to take ownership of (moved from the caller).
77 */
78 explicit Database(std::shared_ptr<pqxx::connection>&& conn); // `explicit` prevents an accidental implicit conversion from a bare pointer.

85 /**
86 * @brief Returns whether a row exists in a table for the given column value.
87 * @details Builds `SELECT EXISTS (...)` using `quote_name` for the table and column to
88 * prevent SQL injection, binding only the value as a parameter.
89 * @param[in] table Table name (identifier, quoted).
90 * @param[in] column Column name (identifier, quoted).
91 * @param[in] value Value bound to the `$1` placeholder.
92 * @return `true` if the row exists; `false` if it does not or if the query threw.
93 * @note A query error is indistinguishable from "not found" here (both return `false`);
94 * use check_connection() when that distinction matters.

96 bool checkExists(const std::string& table, const std::string& column, const std::string& value); // Returns true only when at least one matching row was found.

104 /**

112 // The statement uses $1, $2, ... placeholders; the values travel separately in params. This
113 // separation is what keeps user-supplied values from being interpreted as SQL code.
114 /**
115 * @brief Executes a parameterised query and converts the result rows to JSON.
116 * @details Runs the statement through TransactionType (committed only when it is a
117 * `pqxx::work`). For a json array every result row is appended; for a single
118 * json object only the first row is returned.
119 * @tparam jsonType `jsoncons::json` (first row) or `jsoncons::json::array` (all rows).
120 * @tparam TransactionType Transaction wrapper, e.g. `pqxx::nontransaction` or `pqxx::work`.
121 * @param[in] query SQL text with `$1, $2, ...` placeholders.
122 * @param[in] params Values bound to those placeholders.
123 * @return The converted value, or `std::nullopt` if any exception was caught.
124 */
125 template <typename jsonType, typename TransactionType> // One template serves both "first row" and "all rows" and both transaction kinds.
126 std::optional<jsonType> executeQuery(const std::string& query, const pqxx::params& params = {}); // The empty default lets callers run queries with no parameters.
127
128 /**
