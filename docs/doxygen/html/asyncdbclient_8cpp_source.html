2 * @file asyncdbclient.cpp
3 * @brief Implementation for asyncdbclient: Stores the supplied client, sharing ownership with the caller.
4 * @details This file turns the declarations in asyncdbclient.hpp into working code. The constructor simply takes
5 * ownership of a ready-made Drogon client; the factory reads the database settings from the Store, asks
6 * Drogon to build a PostgreSQL client and sets its execution timeout; the last function formats those
7 * settings into the text string that PostgreSQL's client library understands.
8 *
9 * WHY THIS FILE MATTERS IN THE SERVER:
10 * This is where the asynchronous database client is actually created. During startup Server::run() calls
11 * AsyncDbClient::createClient() when DB_ASYNC is enabled, so this file decides which host, port, database, user,
12 * password and SSL mode the server connects with, and how large the connection pool is. Every async query made by
13 * the database controllers ultimately goes through the client built here. Without it, the Store would have no
14 * client to hand to the controllers and every DB_ASYNC request would report the database as unavailable.
15 *
16 * CONCEPTS TO LEARN (for beginners):
17 * - Drogon DbClient: https://drogon.docsforge.com/master/database/
18 * - std::shared_ptr (ownership shared between callers): https://en.cppreference.com/w/cpp/memory/shared_ptr
19 * - std::move (transferring ownership instead of copying): https://en.cppreference.com/w/cpp/utility/move
20 * - fmt string formatting: https://fmt.dev/
21 * - PostgreSQL connection strings: https://www.postgresql.org/docs/current/libpq-connect.html#LIBPQ-CONNSTRING
22 *
23 * @author Amr Osman <dr3mro@gmail.com>
24 * @date 2026-11-16

45/**
46 * @brief Creates the Drogon Pg client from the Store's database configuration.
47 * @details `newPgClient` receives the generated connection string and `DB_MAX_CONN`; the timeout is then set from
48 * `DB_ACQUIRE_TIMEOUT_MS`. Any connection-establishment work is left to Drogon.
49 */
50std::shared_ptr<drogon::orm::DbClient> AsyncDbClient::createClient()
51{
52 const auto& config = Store::getObject<Configurator>()->get<Configurator::DatabaseConfig>(); // Fetch the shared configuration from the Store and read just the DB section; `const&` avoids copying it.
53 auto client = drogon::orm::DbClient::newPgClient(connectionString(config), config.max_conn); // Drogon builds the PostgreSQL pool: connection text first, maximum number of connections second.
54 // Drogon's DbClient::setTimeout is an SQL execution timeout: it cancels a running command.
55 // It is not a pool-acquire timeout, despite the DB_ACQUIRE_TIMEOUT_MS name; Drogon takes seconds.
56 // The setting still comes from the DB_ACQUIRE_TIMEOUT_MS variable, so the name documents intent while the
57 // division below adapts the value to what this Drogon API actually measures.
58 client->setTimeout(static_cast<double>(config.acquire_timeout_ms) / 1000.0); // Convert milliseconds to seconds; the cast forces floating-point division so 1500 ms becomes 1.5 s, not 1 s.
59 return client; // Hand the shared pointer back; the caller wraps and registers it in the Store.
60}

62/**
63 * @brief Formats the libpq connection string, mapping `config.ssl` to `sslmode`.
64 * @details `connect_timeout` is a fixed two seconds, independent of DB_* tuning; host and SSL settings may be overridden by
65 * the container image but still arrive through this one configuration object.
66 */
67std::string AsyncDbClient::connectionString(const Configurator::DatabaseConfig& config)
68{
69 // The container image overrides DB_HOST and DB_SSL; both flow through the same DatabaseConfig.
70 // That is why nothing special is done here: whichever source supplied the values, they are already in `config`.
71 return fmt::format("host={} port={} dbname={} user={} password={} connect_timeout=2 sslmode={}", config.host, config.port, config.name, config.user, // Each `{}` is replaced by the next argument, producing one libpq keyword/value string; note the password is included in clear text, so never log it.
72 config.pass, config.ssl ? "require" : "disable"); // The boolean SSL flag becomes the word PostgreSQL expects; a fixed 2 s connect timeout keeps startup attempts short.
73}
