1/**
2 * @file main.cpp
3 * @brief Process entry point: build the Server and translate uncaught exceptions into a failure exit status.
4 *
5 * @details This file contains nothing but the program's main() function. It creates a single Server object on the heap
6 * using a smart pointer, then hands control to Server::run(). If anything throws a C++ exception during setup
7 * or shutdown, it prints a short reason to standard error and exits with a failure status.
8 *
9 * WHY THIS FILE MATTERS IN THE SERVER:
10 * This is where the whole process begins. The operating system calls main() first; main() creates the Server, and the
11 * Server in turn configures and runs Drogon (the web framework) together with all the routes, filters and database
12 * helpers. Without this file there would be no starting point, so nothing would ever listen for HTTP requests. main()
13 * is also the last line of defence: it turns an uncaught exception into a readable error message and a non-zero exit
14 * code, which is what process supervisors and Docker expect when a program fails.
15 *
16 * CONCEPTS TO LEARN (for beginners):
17 * - RAII / smart pointers (std::unique_ptr): https://en.cppreference.com/w/cpp/memory/unique_ptr
18 * - Exceptions and try/catch: https://en.cppreference.com/w/cpp/language/exceptions
19 *
20 * @author Amr Osman <dr3mro@gmail.com>
21 * @date 2026-11-16
22 */

31/**
32 * @brief Constructs the Server and transfers control to it.
33 *
34 * @details There is no command-line parsing: every setting is read from the environment by Configurator while the
35 * Server is constructed. The unique_ptr owns the Server for the whole process; because Server::run() blocks
36 * until the event loops stop, the object survives long enough to finish its post-run shutdown sequence.
37 * @param[in] argc Unused; retained only for the standard signature.
38 * @param[in] argv Unused; retained only for the standard signature.
39 * @return The status returned by Server::run(), or EXIT_FAILURE if a std::exception escapes it.
40 * @note Only std::exception is caught; an exception that does not derive from it would terminate the process.
41 * @see Server::run()
42 */
43int main([[maybe_unused]] int argc, [[maybe_unused]] char** argv) // Program entry point; argc/argv are kept only because the C++ standard requires this shape.
44{
45 try // Guard the entire startup and shutdown so a thrown exception cannot crash the process silently.
46 {
47 std::unique_ptr<Server> server = std::make_unique<Server>(); // Own the Server on the heap; a unique_ptr frees it automatically at scope exit.
48 return server->run(); // Start the web server and pass its exit status back to the OS; this call blocks until the event loops stop.
49 }
50 catch (const std::exception& exception) // Reached only if an exception escaped the try block above.
51 {
52 std::cerr << "Server Error: " << exception.what() << '\n'; // Print the reason to stderr, keeping errors separate from normal logs.
53 return EXIT_FAILURE; // Tell the OS or supervisor the process failed, instead of accidentally reporting success.
54 }
